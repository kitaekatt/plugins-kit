Test suite for the secrets-kit plugin covering convergence, destination safety, the pre-commit guard, cross-process locking, permission handling, seeding, and entry recovery

This is the pytest suite for the secrets-kit plugin. Crypto is a subprocess boundary the suite wraps with a reversible stand-in, so every test exercises convergence logic, destination safety, locking, and permission handling against real git repos without depending on the age binary. The shared fixture layer builds expensive git trees once per process and hands each test an independent copy, keeping wall time low despite driving real git commands throughout.

Where to start

Open tests/secrets-kit/conftest.py first: every test depends on its fixtures (the fake age, the fleet, the git-tree templates), and understanding those contracts is prerequisite to reading any individual test file.

Shared fixtures

  • tests/secrets-kit/conftest.py -- Fixtures for the whole suite: reversible stand-in crypto, a seeded fleet, session-scoped git-tree templates, and Windows DACL setup.
  • tests/secrets-kit/sk_publish.py -- Two publish helpers: an ordinary commit-and-push for simulating a peer, and one that calls the plugin's real publication path for security-property tests.
  • tests/secrets-kit/sk_testlib.py -- Per-process git-tree copies (roughly twenty times cheaper than per-test init), path rewriting for relocation, and owner-only file assertions.

Convergence

  • tests/secrets-kit/test_converge.py -- The core write/skip/fail logic: steady-state no-decrypt, self-healing on deletion, tamper detection, blob rotation, entry and profile removal, failure classification, and credential-safe output.

Destination safety

  • tests/secrets-kit/test_dest_guard.py -- The tracked-tree exposure predicate, its git-output parsing, stale environment-variable handling, and the add-time refusal that stops plaintext entering a consumer repo.
  • tests/secrets-kit/test_destination_leaf.py -- Symlink and leaf-slot handling: exposed slots refuse before read, matching leaves replace without touching the referent, and parent-alias spellings resolve to the physical root.
  • tests/secrets-kit/test_destination_ownership.py -- Collision refusal across execution orders, failed-owner slot reservation, invalid-ownership preservation, and consumer-facing failure reporting.
  • tests/secrets-kit/test_destination_retirement.py -- Ownership moves, durable retirements with checkpoint-and-retry, rename handovers, and fresh-process restart that retries only the persisted retirement.

Pre-commit guard

  • tests/secrets-kit/test_guard.py -- Installs the hook, then drives real git commit through it: plaintext refusal, binary-ciphertext scanning, filename allowlist enforcement, and the index-not-worktree read.

Seeding and entry authoring

  • tests/secrets-kit/test_init.py -- The one irreversible verb: seeds a fresh repo, refuses a remote already seeded (the incident regression), and rolls back a seed that cannot publish.
  • tests/secrets-kit/test_entry_recovery.py -- Fault recovery for add, update, and remove: foreign-work refusal before sync or crypto, malformed private-record handling, and epoch preservation before a clean retry.

Cross-process locking

  • tests/secrets-kit/test_operation_lock.py -- Spawns real child processes to verify a held lock refuses a second process before any protected work, releases cleanly after failures, and survives an exec child.

Permission handling

  • tests/secrets-kit/test_perms.py -- ACL tightening on Windows (a regression suite for a real outage) and POSIX chmod behavior.
  • tests/secrets-kit/test_permission_drift.py -- Matching-content permission checks: a widened mode is repaired without re-decrypting, faults retain the state row, and the public consumers report the result.

Agefile boundary

  • tests/secrets-kit/test_agefile.py -- Pins the exception taxonomy at the subprocess boundary: DecryptError only for a completed nonzero exit; missing binary, spawn failure, and timeout propagate as their own error type.

Orphan cleanup

  • tests/secrets-kit/test_orphan_retry.py -- What happens when an orphan file cannot be unlinked: the state row persists, the failure is reported without a passphrase remedy, and a later pass retries from saved evidence.

Golden data

  • tests/secrets-kit/golden -- Supporting fixture data and additional test modules used by the suite.
