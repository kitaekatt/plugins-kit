Secrets-kit plugin test suite for convergence, destination safety, pre-commit guards, repository operations, manifest validation, and operation locks

This directory is the test suite for the secrets-kit plugin. Real age is swapped for a reversible stand-in, so the suite exercises the convergence logic (what gets written, what fails, how it is classified) against a temporary filesystem instead of real crypto. Expensive git trees are built once per process and copied out to keep the run fast. Most of the tests pin destination safety: the plugin must never land plaintext inside a repository.

Where to start

Start with tests/secrets-kit/conftest.py: the fleet fixture seeds a secrets repo and a configured machine, and fake_age is the reversible crypto every convergence test runs against. tests/secrets-kit/sk_testlib.py explains why the suite copies git trees instead of initializing them.

Routes

  • Read a convergence test
    1. tests/secrets-kit/conftest.py builds the fleet and the reversible crypto.
    2. tests/secrets-kit/test_converge.py takes those fixtures and asserts what converge writes, skips, and reports as a failure.
  • Follow the hardened publish path
    1. tests/secrets-kit/sk_publish.py offers owned_commit_and_push, which mirrors what the plugin's authoring does.
    2. It calls the plugin's _commit_owned and _publish_owned directly, so a security test exercises the real publication, not a stand-in.

Harness

  • tests/secrets-kit/conftest.py seeds the repo and a configured machine; fake_age is the reversible crypto every test runs against.
  • tests/secrets-kit/sk_testlib.py: copy_git_tree hands each test a real, independent git repo; copying beats git init on cost.
  • tests/secrets-kit/sk_publish.py: fixture_commit_and_push simulates a peer, while owned_commit_and_push exercises the plugin's real publication path.

Convergence and placement

  • tests/secrets-kit/test_converge.py the core pass: writes a machine's profile, self-heals drift, deletes on removal, reports locked and config failures.
  • tests/secrets-kit/test_agefile.py the age process boundary; only a completed nonzero exit is a DecryptError, so a missing binary never reads as locked.
  • tests/secrets-kit/test_permission_drift.py, tests/secrets-kit/test_perms.py and tests/secrets-kit/test_private_output.py cover mode repair, placement, and private-output checks.

Destination safety

  • tests/secrets-kit/test_dest_guard.py the tracked-tree guard: the exposure predicate plus the add-time and convergence refusals.
  • tests/secrets-kit/test_destination_leaf.py leaf slots and static links, exercised through real consumers.
  • tests/secrets-kit/test_destination_ownership.py planning and conservative orphan ownership.
  • tests/secrets-kit/test_destination_retirement.py ownership moves, durable retirements, and handovers.
  • tests/secrets-kit/test_orphan_retry.py a failed orphan delete is checkpointed and retried.

The pre-commit guard

  • tests/secrets-kit/test_guard.py drives the real shell hook through a real git commit; it reads the index, not the worktree.

Seeding and recovery

  • tests/secrets-kit/test_init.py seeding decides from the remote and rolls back if the seed cannot publish.
  • tests/secrets-kit/test_entry_recovery.py an entry fault preserves the owned epoch for a clean retry.
  • tests/secrets-kit/test_secrets_bootstrap.py, tests/secrets-kit/test_seed_recovery.py, tests/secrets-kit/test_rotation_recovery.py and tests/secrets-kit/test_terminal.py cover the bootstrap, seed, and rotation recovery paths.

Repository, manifest, and locks

  • tests/secrets-kit/test_manifest.py config and manifest loading, validation, and variable expansion.
  • tests/secrets-kit/test_operation_lock.py whole operations contend across independent processes.
  • tests/secrets-kit/test_repo.py, tests/secrets-kit/test_repo_binding.py, tests/secrets-kit/test_repo_display_cli.py, tests/secrets-kit/test_sync_view.py and tests/secrets-kit/test_update_metadata.py cover repo, binding, display, sync-view, and metadata checks.
  • plugins/secrets-kit The plugin these tests exercise: convergence, the pre-commit guard, seeding, and the CLI.
