plugins-kit maintainer reference: standards, design records, procedures, platform facts, and dated measurements

This directory holds maintainer reference for the plugins marketplace: standing criteria, design records, measured platform facts, and dated audits. Documents are read when a task calls for them, not loaded into every session. Dated records preserve evidence and are not updated to match later trees.

Where to start

Open docs/reference/publish-reconcile.md before a release. Open docs/reference/plugin-opinion-razor.md before adding or keeping a workflow opinion.

Routes

  • Check adapter candidates
    1. docs/reference/adapters.md defines the method and admission bar.
    2. docs/reference/adapters-negative-results.md lists closed experiments.
  • Publish with package targets
    1. docs/reference/publish-reconcile.md covers release flow and partial releases.
    2. docs/reference/package-release.md covers imported library targets.
