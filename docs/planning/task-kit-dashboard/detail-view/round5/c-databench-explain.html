Concept C · databench style

Intent lenses, inside databench

This is the approved task detail view, with the same content and the same three lenses, drawn as a page inside databench instead of as a separate dashboard.

What changed from round 4 C

  • Styling source. Colors, type, spacing, the top bar, the context toolbar, the list surface, the segmented controls and the footer come from the databench web client stylesheet and the shared index-pages style. The theme is databench's dark theme; the light and dark toggle is gone.
  • Spend control removed. The spend checkbox and the answering service on and off switch are gone from the task view. Spend is configured in databench settings only. The task view shows the service state, the answer order and whether paid answers are allowed as plain read-only text, plus a Generation settings link.
  • Navigation. A Tasks entry sits in the databench toolbar beside home, directory tree, comments and entities, and is selected. The breadcrumb reads plugins-kit › Tasks.
  • Unchanged. The list and its sorting, the row marks, the Orient, Decide and Trace tabs, the answer cards with their answerer and as-of labels, the exact state box, the decision box and the health line.

What you are looking at

The list of open tasks with task-kit-extraction opened on the Orient lens. The sample answers come from that task's own record. One answer is marked stale because a later plan edit exists; the decision box says paid answers are waiting because the generation settings do not allow them.

Judge this

Does it read as a page of databench? Is the read-only settings link enough, or should the task view show nothing about generation at all?
