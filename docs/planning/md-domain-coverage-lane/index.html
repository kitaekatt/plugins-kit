Planning documents that design, measure, and validate md-domain CLAUDE.md coverage and generation.

This directory holds the planning record for one md-domain capability: deciding whether code is covered by the agent instruction files that load for it, and whether generated documents survive review. The documents are ordered as design, measured runs, independent adjudication, and regression criteria. The recurring distinction is between a document that is internally consistent and a document that changes what a bounded reviewer can catch. Shipped behavior is described by the skill references outside this directory; these files record why the shipped lane has its current shape.

Where to start

Open docs/planning/md-domain-coverage-lane/README.md first for the scope boundary and shipped status. Use docs/planning/md-domain-coverage-lane/coverage-lane-spec.md when you need the normative lane design.

  • Audit the false-claim finding
