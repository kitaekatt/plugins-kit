Design records, implementation plans, and investigation reports for the plugins-kit project

This directory is the project's working paper trail: the design records, implementation plans, and investigation reports written while the plugins were built. Each document describes code that lives beside it but is never shipped into a plugin cache, so it may carry maintainer-only detail a consumer's machine would never see. Folders are named for the plugin or subsystem they serve, and a file sits at the top level when a question crosses that boundary. Two areas have pages of their own and are left out of this one: the md-domain coverage planning and the maintainer reference. The cards above route to them.

Where to start

There is no single entry point; the folders are the map. Open the docs/planning/bootstrap/MILESTONES.md when you are picking up the plugin foundation, because it records what shipped in each milestone and which gaps each one closed.
