The plugins-kit marketplace: independently installable Claude Code plugins for code review, LLM dispatch, job execution, Hue scenes, PDF rendering, secrets, tasks, and Unreal Engine automation, provisioned by the bootstrap engine and linked through shared libraries

This is the plugins-kit marketplace: a shelf of independently installable Claude Code plugins, each a self-contained box the provisioning layer brings online at session start. A plugin declares its needs in a JSON manifest, and the engine installs system tools, builds a Python venv from its pyproject, and links shared libraries across venv boundaries. Three plugins are frozen legacy surfaces that redirect to a maintained successor. The organizing principle is one directory per installable unit, with capabilities shared through linked libraries rather than duplicated.

Where to start

plugins/CLAUDE.md for the plugin-wide conventions and the opinion-razor register. For the provisioning model, the plugins/bootstrap/README.md is the shortest route to understanding how a machine reaches a working state.

Marketplace conventions

plugins/CLAUDE.md -- the plugin-wide authoring guide: the opinion-razor test, the register of deliberately unconfigurable stances, and the shared-lib rationale. Open it before editing any plugin.

Provisioning substrate

plugins/bootstrap -- the engine that reads each kit's manifest at session start: installs tools, builds venvs, links shared libraries, seeds config. The README is the human entry point.

plugins/bootstrap-stuck-fix -- a disposable remediation plugin for two registry defects that wedge a machine on old bootstrap. Superseded natively at 0.62.0; kept published until every machine converges.

Code review gates

plugins/git-kit -- pre-push multi-agent review for local git changes: partitions a diff, fans out reviewers per chunk, validates each finding independently, and remembers declined findings.

plugins/p4-kit -- the Perforce equivalent for pending changelists: auto-shelves for diff content, applies the same validator and ledger mechanics.

LLM access and job execution

plugins/llm-kit -- the maintained consolidation: LLM completion routing, durable agent jobs, and batch content pipelines in one shared library and CLI.

plugins/llm-scripting-kit -- frozen legacy. The LLM access layer llm-kit superseded; pointer-only releases.

plugins/job-kit -- frozen legacy. The durable job runner replaced by llm-kit's jobs group.
