The Claude Code plugin marketplace: independently installable plugins sharing the bootstrap provisioning engine and llm-scripting-kit access layer, covering code review, durable job execution, LLM endpoint dispatch, Hue scene synchronization, PDF rendering, fleet secrets provisioning, prompt statusline, cache forensics, markdown auditing, and Unreal Engine automation.

This directory holds the independently installable Claude Code plugins for the marketplace. Each plugin is a separate package, but they share provisioning. The sections below name the plugin-level entry docs and their jobs.

Where to start

Open plugins/CLAUDE.md first: it states the authoring rules and the register of opinions that are deliberately not configurable.

Routes

  • Run a durable job
    1. plugins/job-kit/bin/job-kit run
    2. plugins/job-kit/bin/job-kit status <run-id>
    3. plugins/job-kit/bin/job-kit resume <run-id>
  • Set up a Hue bridge
    1. plugins/hue-kit/bin/hue-kit discover
    2. plugins/hue-kit/bin/hue-kit pair
    3. plugins/hue-kit/bin/hue-kit start
    4. plugins/hue-kit/bin/hue-kit validate
    5. plugins/hue-kit/bin/hue-kit apply --yes
