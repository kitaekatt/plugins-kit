The llm_kit library: LLM completion routing across OpenRouter, Claude, Codex and OpenCode backends, durable agent jobs, batch content pipelines, and the front-door HTTP server.

This directory is the llm-kit package. It implements the llm-kit command, a shared completion protocol for OpenAI-compatible, Claude CLI, Codex, and OpenCode backends, durable jobs, batch pipelines, and an OpenAI-compatible front door. It covers the command surface, completion protocol, adapter backends, dispatch, registry, jobs, pipeline, front door, execution, schema, storage, and scaffold modules.

Start

Read plugins/llm-kit/lib/llm_kit/cli/__init__.py for the command map and plugins/llm-kit/lib/llm_kit/completion/types.py for the protocol.
