The secrets-kit package that provisions fleet secrets from age-encrypted blobs into machine-local files and guards authoring operations.

This is the stdlib-only Python package behind the secrets-kit plugin. It reads the fleet's age-encrypted blobs from a private git repo and materializes them into machine-local files under strict permissions, and it refuses to author into the secrets repo unless its guards are in place. The package is split by which side of the session it runs on: an idempotent pass that every session start executes, and the write path that a person starts and the package hardens. Two constraints shape that split. Blobs are encrypted to a public key, so day-to-day operations need no passphrase at all; the master passphrase is typed once, on a real terminal, and never passes through Python. Every failure is an error that carries its own remedy, so the pass can tell an agent exactly what to do next.

Where to start

Open converge.py first: it is the pass that runs on every session start, and every other module exists to make one of its steps safe. When a machine is not converging, the pass's stable failure keys name the step to read next.

Routes

  • Session pass: converge.py -> manifest.py -> repo.py -> agefile.py -> state.py. The pass loads the declarations, refreshes the clone, decrypts each selected blob, and records the hashes that make the next run free.
  • Unlock, one time: terminal.py -> agefile.py. The verb runs in a real terminal window so age can prompt, and the unlocked identity lands as the 0600 cache the pass then uses.
  • Seed or rotate: guard.py -> authoring.py -> agefile.py -> repo.py. The guard is verified first, the operation runs under its recovery record, age produces the new identity and re-encrypted blobs, and the commit publishes them.

The convergence pass

  • converge.py -- The idempotent pass: check by hash, fix by decrypt-and-write, with every outcome classified as machine-fixable or needs-a-person. Open when a machine is not converging.
  • state.py -- The machine-local state ledger: which blob produced which plaintext, so the steady pass is free and a tampered or truncated file heals itself. Open when you need to reason about what this machine already materialized.

Declarations

  • manifest.py -- Loads and validates the two declarations (the machine-facing one and the repo-side manifest) and resolves destination paths with variable expansion. Open when an entry's destination, mode, or profile looks wrong.

Age and the passphrase

  • agefile.py -- The thin wrapper over the age binaries: the passphrase paths run on the user's terminal, and everything the unattended pass does needs no passphrase at all. Open when a decrypt fails or you need to know which age exit means what.
  • terminal.py -- Opens the interactive verbs in a real terminal window on macOS, Linux, and Windows so the passphrase never reaches a transcript; falls back to naming the manual command. Open when unlock or init does not open a window.

Authoring and its guards

  • authoring.py -- The write side: seed, add, rotate, and remove, each run under a recovery record that blocks ordinary callers until an uncertain publication is reconciled privately. Open when authoring is stopped and the remedy names reconciliation.
  • guard.py -- Installs and verifies the fleet-secrets pre-commit guard in every clone, and refuses authoring on an unguarded clone. Open when a commit was, or was not, blocked by the guard.
  • operation_lock.py -- Non-blocking single ownership of the plugin data directory, on POSIX and Windows. Open when two operations collide or a lock error appears.
  • perms.py -- Permission tightening: chmod on POSIX, icacls on Windows, plus atomic private-file writes so a secret never exists at a loose mode. Open when a file lands with the wrong permissions.
  • repo.py -- Clones and refreshes the private repo without ever blocking a session, scrubs inherited git variables before every invocation, and classifies each destination for exposure to someone else's git. Open when a fetch, a publish, or a destination check misbehaves.

Package surface

  • __init__.py -- The error taxonomy every other module raises (each error carries its remedy) and the one place that renders the CLI invocation, because the install shim is not on PATH. Open when a message hands out a command that needs fixing, or you need the exception hierarchy.
