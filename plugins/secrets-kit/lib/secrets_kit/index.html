The secrets-kit package that provisions fleet secrets from age-encrypted blobs into machine-local files and guards authoring operations.

This package is the Python side of the secrets-kit plugin: it materializes age-encrypted fleet secrets as machine-local files and guards the authoring operations that publish them. It is stdlib-only and deliberately engine-agnostic, so the session-start caller and the CLI can both drive it. The package separates unattended convergence from interactive passphrase work, because the passphrase is only needed when a machine is unlocked or identity is rotated.

Where to start

plugins/secrets-kit/lib/secrets_kit/__init__.py for the trust model and shared error taxonomy; open plugins/secrets-kit/lib/secrets_kit/converge.py when the question is what the session-start pass does.

Routes

  • Session-start convergence
    1. plugins/secrets-kit/lib/secrets_kit/converge.py loads declarations, classifies the host, and runs the pass under the operation lock.
    2. plugins/secrets-kit/lib/secrets_kit/manifest.py validates the declarations and resolves each destination for this machine.
    3. plugins/secrets-kit/lib/secrets_kit/repo.py clones or refreshes the private repo without blocking a session on connectivity.
    4. plugins/secrets-kit/lib/secrets_kit/agefile.py decrypts the selected blobs with the unlocked identity.
    5. plugins/secrets-kit/lib/secrets_kit/state.py records blob and destination hashes so unchanged secrets cost nothing.
  • Author a protected secret
    1. plugins/secrets-kit/lib/secrets_kit/guard.py installs and verifies the pre-commit guard before any write.
    2. plugins/secrets-kit/lib/secrets_kit/authoring.py stages encrypted proposed outputs under private recovery custody.
    3. plugins/secrets-kit/lib/secrets_kit/repo.py runs the guarded local writes and publication checks.
    4. plugins/secrets-kit/lib/secrets_kit/agefile.py encrypts new blobs to the fleet public key.

Declarations and destination resolution

  • plugins/secrets-kit/lib/secrets_kit/manifest.py validates the two declarations, expands variables to a fixpoint, and resolves each secret destination for this machine.

Convergence and machine state

  • plugins/secrets-kit/lib/secrets_kit/converge.py runs the idempotent session pass: check, fix, and classify failures as actionable by the agent or reserved for the user.
  • plugins/secrets-kit/lib/secrets_kit/state.py keeps per-entry hashes and pending retirements, making steady-state passes skip decryption.
  • plugins/secrets-kit/lib/secrets_kit/repo.py clones and refreshes the private repo, scrubs hostile git environment, and classifies destination exposure.

Authoring safety

  • plugins/secrets-kit/lib/secrets_kit/guard.py installs the pre-commit guard and the deny-by-default ignore file into every clone.
  • plugins/secrets-kit/lib/secrets_kit/authoring.py protects seed, add, rotate, and remove operations with private recovery evidence and custody checks.
  • plugins/secrets-kit/lib/secrets_kit/operation_lock.py gives one process ownership of the physical data directory before protected work.

Shared plumbing and platform support

  • plugins/secrets-kit/lib/secrets_kit/agefile.py wraps age and age-keygen, keeps passphrase paths interactive, and decrypts blobs without a passphrase.
  • plugins/secrets-kit/lib/secrets_kit/terminal.py opens a terminal window for interactive verbs on Windows, macOS, and Linux.
  • plugins/secrets-kit/lib/secrets_kit/perms.py tightens file and directory permissions honestly on POSIX and Windows.
  • plugins/secrets-kit/lib/secrets_kit/__init__.py defines shared errors with remedies and renders the correct CLI invocation for whichever version is printing.
