The secrets-kit package that materializes age-encrypted fleet secrets into machine-local files through an idempotent convergence pass, a pre-commit guard, and an authoring-recovery protocol.

Secrets-kit is the stdlib-only package that turns age-encrypted fleet secrets into plain files on each machine. It splits by the two ways secrets move: an unattended convergence pass that runs every session to pull a machine up to date, and interactive authoring verbs that only a human can drive, because the fleet passphrase is typed into a real terminal. Every module raises one of two error types that carry a ready remedy, and every path that writes a secret is checked, locked, and permission-tightened first. The organizing idea is that the passphrase never passes through Python: the age tool reads it from a terminal, so the unattended pass needs no terminal at all, and the interactive verbs are the ones that open one.

Where to start

Open plugins/secrets-kit/lib/secrets_kit/converge.py first: it is the single entry the session-start pass calls, and reading it top to bottom shows how every other module is reached and where the pass stops to ask a human.

Routes

  • Converge a machine's secrets
    1. plugins/secrets-kit/lib/secrets_kit/converge.py loads the declarations through plugins/secrets-kit/lib/secrets_kit/manifest.py and takes the data-directory lock through plugins/secrets-kit/lib/secrets_kit/operation_lock.py.
    2. plugins/secrets-kit/lib/secrets_kit/repo.py clones or refreshes the fleet repo; a failed fetch only logs, it never blocks the session.
    3. For each selected entry, plugins/secrets-kit/lib/secrets_kit/agefile.py decrypts the blob, plugins/secrets-kit/lib/secrets_kit/perms.py writes it with tight permissions, and plugins/secrets-kit/lib/secrets_kit/state.py records the hashes that make the next pass a no-op.
  • Author or rotate a secret
    1. plugins/secrets-kit/lib/secrets_kit/guard.py installs and verifies the pre-commit guard before any authoring act.
    2. plugins/secrets-kit/lib/secrets_kit/agefile.py encrypts the plaintext to the fleet public key; a public-key step that needs no passphrase.
    3. plugins/secrets-kit/lib/secrets_kit/repo.py commits and publishes under the authoring timeout; it runs longer than a fetch because the pre-commit hook spawns once per staged path.
  • Unlock a machine once
    1. plugins/secrets-kit/lib/secrets_kit/terminal.py opens a real terminal window running the unlock verb.
    2. plugins/secrets-kit/lib/secrets_kit/agefile.py inherits age's own prompt and writes the private identity cache through plugins/secrets-kit/lib/secrets_kit/perms.py.
    3. plugins/secrets-kit/lib/secrets_kit/converge.py then runs for the life of that identity with no further passphrase.

The convergence pass

  • plugins/secrets-kit/lib/secrets_kit/converge.py The check-and-fix pass the session starts; open it to see the two-outcome (auto or ask) split and where the pass stops to prompt a human.
  • plugins/secrets-kit/lib/secrets_kit/state.py The machine-local ledger of materialized hashes and modes; open it to see why the steady pass costs nothing.

Declarations

  • plugins/secrets-kit/lib/secrets_kit/manifest.py Loads the declaration data: repo, machine, and profiles on one side, entries and destinations on the other; open it to change what a given machine holds.

age operations

  • plugins/secrets-kit/lib/secrets_kit/agefile.py The subprocess wrapper around age; open it for the encrypt, decrypt, and identity wrap and unwrap that never route the passphrase through Python.

Keeping secrets out of git

  • plugins/secrets-kit/lib/secrets_kit/repo.py Clones and refreshes the fleet repo, scrubs the inherited git environment, and classifies destination exposure; open it for clone, fetch, or leak questions.
  • plugins/secrets-kit/lib/secrets_kit/guard.py Installs and verifies the pre-commit guard and the deny-by-default ignore rules; open it when a clone has no guard or a stray file could stage.

Platform safety rails

  • plugins/secrets-kit/lib/secrets_kit/perms.py chmod on POSIX, icacls on Windows, and the private atomic write; open it for any wrong-permission or torn-write symptom.
  • plugins/secrets-kit/lib/secrets_kit/operation_lock.py The cooperative nonblocking lock on the data directory; open it for another-operation-owns-the-lock failures.
  • plugins/secrets-kit/lib/secrets_kit/terminal.py Spawns a real terminal window for the interactive verbs; open it for unlock or seed windows that will not open.

Authoring recovery

  • plugins/secrets-kit/lib/secrets_kit/authoring.py The private recovery protocol for an uncertain publication; open it when ordinary operations are stopped and a recovery directory is present.

Package root

  • plugins/secrets-kit/lib/secrets_kit/__init__.py The two error types that carry remedies and the CLI command renderer; open it to see the failure taxonomy.
