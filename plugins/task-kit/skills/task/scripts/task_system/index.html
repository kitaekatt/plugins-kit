The task-system implementation: lifecycle verbs for task folders, cross-project discovery and validation, and the local read-only dashboard server.

Task-system package provides task-folder verbs. It covers validation, discovery, projection, and a local read-only viewer. Its modules cover package entry, operations, schemas, review rendering, and dashboard viewer.

Start

Use plugins/task-kit/skills/task/scripts/task_system/validate.py for task classifications and findings, then plugins/task-kit/skills/task/scripts/task_system/discovery.py for task discovery.

Modules

  • plugins/task-kit/skills/task/scripts/task_system/__init__.py package entry.
  • plugins/task-kit/skills/task/scripts/task_system/init.py creates task folder; validates; removes on failure.
  • plugins/task-kit/skills/task/scripts/task_system/state_ops.py work, update, close, reopen.
  • plugins/task-kit/skills/task/scripts/task_system/location_ops.py archive, delete, version-control decisions.
  • plugins/task-kit/skills/task/scripts/task_system/reference_rewrite.py move and rewrite refs.
  • plugins/task-kit/skills/task/scripts/task_system/summary_ops.py optional summaries.
  • plugins/task-kit/skills/task/scripts/task_system/discovery.py finds task folders and refs.
  • plugins/task-kit/skills/task/scripts/task_system/listing.py projects sections and diagnostics.
  • plugins/task-kit/skills/task/scripts/task_system/review_html.py renders review document.
  • plugins/task-kit/skills/task/scripts/task_system/task_items.py plan item checks.
  • plugins/task-kit/skills/task/scripts/task_system/schemas.py YAML schemas.
  • plugins/task-kit/skills/task/scripts/task_system/types.py hand-off type registry.
  • plugins/task-kit/skills/task/scripts/task_system/resolve.py canonicalizes refs and stubs.
