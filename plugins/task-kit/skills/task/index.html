The task skill: data model, CLI verbs, operational protocols, design rationale, and the answers question catalog.

The task skill defines a tracked unit of work with a full lifecycle, exposing sixteen CLI verbs over a folder of markdown and YAML. It routes each verb to a detailed operational protocol and documents the data model, item vocabulary, and design rationale behind the system. The answers question catalog drives a per-task summary engine that computes orientation, decisions, activity, and task-commit answers.

Overview

This capability skill turns a folder of markdown and YAML into a tracked unit of work with a full lifecycle. It defines the data model, exposes sixteen CLI verbs, and documents the operational protocols an agent follows for each state transition. The capability definition routes every verb to a detailed protocol document; the implementation that executes those verbs lives in a subpackage with its own page. Design specs record the rationale for the model and its item vocabulary; a question catalog drives the answers engine that computes per-task summaries.

Where to start

plugins/task-kit/skills/task/SKILL.md is the routing surface: it lists all sixteen verbs, the data model, and the agent-side behaviors in one file. Open it first, then follow the verb to its protocol document in the references directory.

Routes

  • Work a task end to end
    1. plugins/task-kit/skills/task/scripts/task.py work <ref> -- validate, register session, emit skill block
    2. plugins/task-kit/skills/task/references/work-and-hand-off.md -- invoke skills, dispatch, finish
    3. plugins/task-kit/skills/task/scripts/task.py close <ref>
  • Scaffold and validate a new task
    1. plugins/task-kit/skills/task/scripts/task.py init <stub>
    2. plugins/task-kit/skills/task/scripts/task.py validate <ref>
    3. plugins/task-kit/skills/task/references/lifecycle-operations.md -- field contracts and fix-forward rules
  • Export task facts to a consumer
    1. plugins/task-kit/skills/task/references/task-export-protocol.md -- the normative export contract
    2. plugins/task-kit/skills/task/references/task-export.schema.json -- JSON Schema for each document
  • Triage the backlog
    1. plugins/task-kit/skills/task/references/task-triage-protocol.md -- audit, present, ruling procedure
    2. plugins/task-kit/skills/task/scripts/task.py list then archive, close, or update per the user's ruling

Capability and routing

plugins/task-kit/skills/task/SKILL.md -- the complete capability definition: sixteen verb routes, data model summary, CLI invocation pattern, and agent-side gates. Open it to find which protocol document a given task takes you to.

CLI and session hooks

plugins/task-kit/skills/task/scripts/task.py -- the single CLI entry point; 16 subcommands, exit-code conventions, and the initialization block that work emits.

plugins/task-kit/skills/task/scripts/bootstrap_guard.py -- vendored stdlib-only guard; detects whether bootstrap has provisioned the plugin and re-execs under its venv.

plugins/task-kit/skills/task/scripts/task_session_start.py -- the SessionStart hook; refreshes session records on resume and releases registrations on clear.

Operational protocols

The protocol documents in the references subdirectory define how each verb and agent-side behavior works. The core contracts and hand-off template are the two most-loaded; the rest cover lifecycle mutations, queries, review, triage, background workflows, the dashboard, and the export and manage interfaces.

plugins/task-kit/skills/task/references/core-contracts.md -- data model, cwd resolution, merge target, validation behavior, and shared gotchas.

plugins/task-kit/skills/task/references/handoff-template.md -- the folder-authoring guide: project instructions structure, plan contract, task items block, size budgets, and rotation passes.

plugins/task-kit/skills/task/references/example-claude-md.md -- a worked example of the produced project instructions file; read it when the template feels abstract.

plugins/task-kit/skills/task/references/lifecycle-operations.md -- init through move: every mutation verb with its preconditions and output.

plugins/task-kit/skills/task/references/query-operations.md -- list, show, items, and sessions: the read-only surface.

plugins/task-kit/skills/task/references/work-and-hand-off.md -- the work verb's three steps, refresh, and the user-invoked hand-off gate.

plugins/task-kit/skills/task/references/task-triage-protocol.md -- the agent-side triage: select, audit, present, and apply the user's ruling.

plugins/task-kit/skills/task/references/task-export-protocol.md -- the normative export contract: commands, payload fields, answers engine, and negotiation.

plugins/task-kit/skills/task/references/task-manage-protocol.md -- the manager interface: full input, mutation requests, concurrency, and boundaries.

plugins/task-kit/skills/task/references/task-review.md -- the review verb: grouping, orientation answers, and HTML output.

plugins/task-kit/skills/task/references/background-workflows.md -- queue and status: the two capabilities that protect the main thread.

plugins/task-kit/skills/task/references/dashboard.md -- the task view: how task-kit hands facts to Databench and what commands it exposes.

Design rationale

plugins/task-kit/skills/task/design/task-system-design.md -- the v1 design specification: entities, states, relationships, and the governing idea of embedded-YAML typed units.

plugins/task-kit/skills/task/design/task-items-design.md -- the item vocabulary proposal: why item, the task items block contract, and what it deliberately does not add.

plugins/task-kit/skills/task/design/diagrams/task-discovery.html -- interactive data-flow diagram of the discovery and scoped-list pipeline.

Answers catalog

plugins/task-kit/skills/task/questions/catalog.yaml -- the shipped question set: orientation, decisions, activity, and task commits.

Four question definitions in the questions subdirectory each declare their inputs, answer schema, and applicable classifications. plugins/task-kit/skills/task/defaults/answers.yaml ships the model preference order and effort level for the answers chain.
