Content-pipeline-kit plugin packaging: bootstrap configuration, public API surface contract, one-unit worker agent, consumer contract checker, and parallel wave workflow.

This level is the consumer-facing surface around the pipeline library. It includes packaging that installs the plugin, the contract that lists public names, a worker agent definition for one unit, and a workflow script that runs a prepared wave across parallel lanes. A consumer imports the library from its own entry point. The version triple must stay equal, and a repository test enforces lockstep.

Where to start

plugins/content-pipeline-kit/README.md states features and the layer boundary. plugins/content-pipeline-kit/bootstrap.json is for install setup.

Routes

  • Consumer arrives
    1. plugins/content-pipeline-kit/README.md states features and boundary.
    2. plugins/content-pipeline-kit/contract/public-surface.json lists public names.
    3. plugins/content-pipeline-kit/scripts/check_consumer_contract.py checks consumer imports.
  • Change a public name
    1. plugins/content-pipeline-kit/contract/public-surface.json records status, removal version, replacement.
    2. plugins/content-pipeline-kit/scripts/check_consumer_contract.py reads that file.
  • Bump the version
    1. plugins/content-pipeline-kit/.claude-plugin/plugin.json and plugins/content-pipeline-kit/pyproject.toml carry visible halves of the triple.
    2. The library version constant is third; a repository test enforces lockstep.
  • Dispatch a wave
    1. plugins/content-pipeline-kit/workflows/run-ready-wave.js runs a prepared wave across N agent lanes.
    2. plugins/content-pipeline-kit/agents/pipeline-worker.md is the dispatched worker for one unit.
    3. Returned counts are advisory; the execution store is truth.

Surface, worker, and gate

  • plugins/content-pipeline-kit/contract/public-surface.json lists every exported name as public, deprecated, or removed, with removal version and replacement.
  • plugins/content-pipeline-kit/agents/pipeline-worker.md defines one worker unit: claim, answer, submit, revise on compact feedback, report unaddressable failures.
  • plugins/content-pipeline-kit/workflows/run-ready-wave.js runs a prepared wave across parallel lanes; it writes no files, and per-unit results are advisory.
  • plugins/content-pipeline-kit/scripts/check_consumer_contract.py scans Python for content_pipeline names, reports deprecated or removed uses, exits nonzero on removed names, and strict also fails deprecated; static detection misses getattr and string imports.
