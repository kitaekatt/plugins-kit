The library for LLM-in-the-loop batch content pipelines, providing an attributed store, freshness engine, durable execution plane with run tracking and worker protocol, delivery modes, VCS seam, and audit.

This is the Python library behind content-pipeline-kit: generic machinery for LLM-in-the-loop batch content generation. Thirteen subpackages cover records, staleness, validation, context, model calls, generation shapes, durable runs, delivery, version control, round-trip, and oversight. The root re-exports nothing; subpackage import declarations keep the graph a strict DAG.

Where to start

Open plugins/content-pipeline-kit/lib/content_pipeline/__init__.py first: its docstring maps subpackages, names import budgets, and states the submodule-imports-only rule. Keep plugins/content-pipeline-kit/lib/content_pipeline/default_config.yaml beside it for machine-global settings.

Routes

  • Run a tracked wave
    1. plugins/content-pipeline-kit/lib/content_pipeline/cli/run.py - command registry; handlers parse argv and call one store method.
    2. plugins/content-pipeline-kit/lib/content_pipeline/execution/controller.py - prepare_run gates pending units; finalize_run applies accepted units repeat-safely.
    3. plugins/content-pipeline-kit/lib/content_pipeline/execution/drivers/inline.py - run_wave works the wave one unit at a time.
  • Drive a background worker
    1. plugins/content-pipeline-kit/lib/content_pipeline/execution/drivers/claude_bg.py - mints worker id and names a pre-allowlisted invocation per unit.
    2. plugins/content-pipeline-kit/lib/content_pipeline/cli/run.py - protocol command reads a small JSON envelope and splices fenced answer text.
    3. plugins/content-pipeline-kit/lib/content_pipeline/execution/protocol.py - dispatch routes verb to store; claim and apply stay in run plane.

The durable run plane

  • plugins/content-pipeline-kit/lib/content_pipeline/execution/store.py - ExecutionStore: WAL SQLite, per-verb connections, atomic claims; run truth lives here.
  • plugins/content-pipeline-kit/lib/content_pipeline/execution/model.py - record shapes, unit state machine, error taxonomy; pure data.
  • plugins/content-pipeline-kit/lib/content_pipeline/execution - controller, adapter, protocol, wave, drivers, scheduler, status, events, deadlines, failure cache, interrupts, workerpack.

Content records and staleness

  • plugins/content-pipeline-kit/lib/content_pipeline/store - attributed content store: candidates, intermediary values, projection delivery reads.
  • plugins/content-pipeline-kit/lib/content_pipeline/freshness - classify, hashing, two-tier classification, seeding, ensure; one staleness verdict reused everywhere.

Validation and generation shape

  • plugins/content-pipeline-kit/lib/content_pipeline/validate - contract, riders, floor guard; output contracts and disposition.
  • plugins/content-pipeline-kit/lib/content_pipeline/pipeline - Gate, single pass, convergence loop, stages, work units, cell policy.
  • plugins/content-pipeline-kit/lib/content_pipeline/providers - tiered context registry and assembly that builds prompt context.

Model-call layer

  • plugins/content-pipeline-kit/lib/content_pipeline/llm - OpenAI-compatible platform, backend and model resolution, spend ledger, admission gate, convergence, YAML extraction.

Delivery and version control

  • plugins/content-pipeline-kit/lib/content_pipeline/deliver - in-place mutation with do-no-harm marker, revert, changeset choreography; append-only projection writes roll back via backup.
  • plugins/content-pipeline-kit/lib/content_pipeline/vcs - backend seam: git default, Perforce via p4-kit, null for tests.

Oversight: audit, provenance, round-trip

  • plugins/content-pipeline-kit/lib/content_pipeline/audit - auditor, reasoning chain, report; runtime classifiers, six finding kinds, append-only sidecar, rollups.
  • plugins/content-pipeline-kit/lib/content_pipeline/provenance - call audit, provenance records, snapshots, replay.
  • plugins/content-pipeline-kit/lib/content_pipeline/roundtrip - human round-trip: questions out, returns in.

Command-line scaffold

  • plugins/content-pipeline-kit/lib/content_pipeline/cli - scaffold, run, budget, unsupported; argument dispatch, command adapters, preflight hard stop, sticky exclude registry.
