# prototypes

Nursery for experimental skills awaiting graduation. Skills live here while
they prove themselves; a skill graduates to its own plugin only after its
graduation gates (explicit, per-skill criteria that must hold and stay tested)
are met.

## Current inventory

Empty. The plugin ships no skills, so there is nothing to install yet.

## Install

```
/plugin marketplace add kitaekatt/plugins-kit
/plugin install prototypes
```

Expect churn: skills here may change shape or be removed without the
compatibility care a graduated plugin gets.
