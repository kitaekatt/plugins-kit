# prototypes

Nursery for experimental skills awaiting graduation. Skills live here while
they prove themselves; a skill graduates to its own plugin only after its
graduation gates (explicit, per-skill criteria that must hold and stay tested)
are met.

## Status

Inactive archive. The plugin ships no skills and is not published or
installable from the marketplace. Experimental work may stay here while it
proves itself, then graduate to a published plugin with its own install path.

Expect churn: archived skills may change shape or be removed without the
compatibility care a graduated plugin gets.
