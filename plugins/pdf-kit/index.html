The pdf-kit plugin that converts local HTML files to PDFs through headless Chromium.

This is a small Claude Code plugin with one job: turn a local HTML file into a PDF. It renders through headless Chromium via Playwright rather than a pure-Python PDF library, so CSS, web fonts, the page's dark or light theme, and JavaScript all execute exactly as in a real browser. Everything here serves a single command: manifest and dependency files describe the install, a bootstrap script fetches the Chromium binary into Playwright's shared cache, and one skill wraps a deterministic converter script that makes the rendering decisions. The default output is a single-page PDF sized to the content's real height; a flag switches to A4 pagination.

Where to start

Open skills/html-pdf/SKILL.md first: it is the contract for the html-pdf command, with the invocation line, single-page versus A4 modes, scale handling, and the gotchas the converter is built to avoid. When a behavior question needs an answer the skill only summarizes, skills/html-pdf/scripts/html_to_pdf.py is where the rendering decisions are made.

Routes

  • Install the plugin and get Chromium. The plugin manifest's bootstrap dependency starts provisioning: the venv phase pulls playwright and pypdf from pyproject.toml, then custom_bootstrap.py downloads the Chromium binary into the shared browser cache and records the Playwright version and executable path in a marker file. A later run finds the marker current and spends no subprocess.
  • Convert a local HTML file (default single-page). skills/html-pdf/SKILL.md checks that bootstrap ran and that no Chromium requirement is deferred, then invokes skills/html-pdf/scripts/html_to_pdf.py with the venv's python. The script renders the page at a fixed layout width, measures the content's real height, prints one PDF page exactly that tall, and opens the result in the default web browser.
  • Paginate or scale the output. Pass --a4 to paginate to A4, where the page's own @media print rules apply; pass --scale with a fraction or percent to shrink or enlarge the rendering. In single-page mode the scale is applied to the finished PDF as a vector transform, so the layout never reflows.
  • Recover from a missing or stale Chromium. A Playwright version change or a cleared browser cache invalidates the marker, and a failed install is recorded as a deferred requirement instead of read as success. The skill's preflight and the converter's error hint both relay the prepared install command, so you run the one command the plugin recorded and retry.

Manifest and dependencies

.claude-plugin/plugin.json
The plugin's identity: name, version, and the bootstrap dependency that drives install. Open it when bumping the version or reading what the install triggers.
pyproject.toml
The runtime dependencies the plugin venv installs: Playwright for driving Chromium and pypdf for post-render scaling.

Bootstrap provisioning

The one cost to remember: installing the plugin downloads the Chromium browser binary, approximately 180 MB, into Playwright's shared browser cache.

bootstrap.json
Declares the venv imports to verify (playwright, pypdf) and names the custom script that runs after the venv phase.
custom_bootstrap.py
Fetches the Chromium binary, records a marker so steady-state runs stay silent, and turns a failed install into a deferred requirement the skill relays at the point of need.

The skill contract

skills/html-pdf/SKILL.md
Fires only on a direct user request. Carries the exact invocation line, single-page versus A4 modes, scale parsing, and the five gotchas the converter encodes.

The converter

skills/html-pdf/scripts/html_to_pdf.py
The rendering itself: single-page height measurement with two print-time traps neutralized, A4 pagination, vector scaling with pypdf, and opening the result in the default browser. Open it when a layout or output surprise needs an explanation.
