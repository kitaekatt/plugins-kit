Multi-agent code review for local git changes: partitions a diff into chunks, fans out parallel reviewer and validator subagents, and renders confirmed findings as markdown.

This is a Claude Code technique skill that reviews local git changes with parallel subagents. The main thread freezes the working tree as a snapshot and launches one background runner; the runner partitions the diff into chunks, dispatches reviewer and validator subagents per role and per chunk, and returns a rendered markdown report. Reviewer rosters and model assignments come from a three-layer profile table resolved at review time. A persistent ledger collapses previously-declined findings on re-runs, and path-scoped submit gates from ancestor instruction files are discharged against each change.

Where to start

Open plugins/git-kit/skills/git-code-review/SKILL.md for the six-step background_review technique and the fixed runner brief. The ten-step procedure the runner follows is in the plugins/git-kit/skills/git-code-review/references/full-review.md reference.

Routes

  • Run a background review
    1. Pick the target: this session's uncommitted paths or a committed range.
    2. Freeze the working tree into a snapshot.
    3. Launch one background runner; it follows the full procedure and returns findings.
    4. Present findings, review fixes as a delta, land only when asked.
  • Override reviewer profiles
    1. Edit the project or user layer of the three-layer profile table.
    2. Run the profile validation check to confirm the merged table parses.
    3. The next review resolves the merged table at its first step.
  • Add a submit gate
    1. Write the **Submit gate:** block in an ancestor instruction file.
    2. The next review detects the gate and discharges it against the change.
