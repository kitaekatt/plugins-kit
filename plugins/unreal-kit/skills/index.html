Unreal Engine automation skills providing Python data access, in-Editor MCP control, and P4-backed ObjectRedirector cleanup over a shared UE runtime.

Four skill directories sit here, each wrapping one way to automate Unreal Engine from a Claude agent. They share a provisioned venv and project-discovery layer, splitting across two execution channels: host-side Python scripts that work with or without the Editor open, and in-Editor MCP tool calls that drive a live Editor session. A domain skill provides natural-language routing among the three member skills. The redirector-cleanup skill is the only member that requires a Perforce workspace; the other three do not install or require a VCS client.

Where to start

Open plugins/unreal-kit/skills/unreal-domain/SKILL.md first - it maps your intent to the right member skill and execution channel. If you already know which skill you need, jump straight to its SKILL.md.

Routes

  • Run a UE Python script
    1. plugins/unreal-kit/skills/ue-python-api/scripts/ue-runner.cmd selects a standalone, bootstrap, or venv interpreter
    2. plugins/unreal-kit/skills/ue-python-api/scripts/ue_runner.py auto-detects whether the Editor is open
    3. dispatches to remote UDP via upyrc or a headless commandlet
  • Author a Blueprint via MCP
    1. open the Editor with the MCP bridge plugin active
    2. manage_blueprint: create, add_component, create_node, connect_pins
    3. save and verify the .uasset modification time changed
  • Clean up ObjectRedirectors
    1. classify every redirector by P4 safety (fix-up safe, orphaned safe, referenced-broken)
    2. filter via code-reference scan and directory-sample the safe set
    3. apply test CL, soak through a build cycle, then run the full purge
