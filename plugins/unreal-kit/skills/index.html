Unreal Engine automation skills providing Python data access, in-Editor MCP control, and P4-backed ObjectRedirector cleanup over a shared UE runtime.

Three automation skills and one domain router sit here. They cover reading and writing Unreal asset data via Python, driving the live Editor through MCP tool calls, and cleaning up ObjectRedirector assets in Perforce-backed projects. The domain skill routes a request to the right member by channel: host-side Python for data and cleanup, in-Editor MCP for live control. All three share the plugin venv and project-discovery machinery one level up.

Where to start

Open plugins/unreal-kit/skills/unreal-domain/SKILL.md for the routing table: it maps each task to a member skill and states whether the Editor must be open.

Routes

  • Run a script against the Unreal Editor
    1. plugins/unreal-kit/skills/ue-python-api/scripts/ue_runner.py - the host-side runner; auto-detects Editor presence and picks remote or headless commandlet mode.
    2. plugins/unreal-kit/skills/ue-python-api/references/architecture.md - how the mode is chosen, what each supports, and the fallback rules.
  • Clean up ObjectRedirectors in a P4 project
    1. plugins/unreal-kit/skills/fix-up-redirectors/SKILL.md - the six-phase pipeline, mode table, reference-channel audit, and the directory-sample-then-purge strategy.
    2. plugins/unreal-kit/skills/fix-up-redirectors/lib/code_refs.py - the code-reference scanner: finds literal asset paths in source, filters by real mount and on-disk existence, caches the result.
    3. plugins/unreal-kit/skills/fix-up-redirectors/lib/p4cli.py - P4 workspace mapping, pending-CL creation, batch edit and delete, and the query/mutation timeout budgets.
  • Pick the right channel for a task
    1. plugins/unreal-kit/skills/unreal-domain/SKILL.md - the routing table: data access goes host-side, live-Editor control goes MCP, redirector cleanup goes host-side plus P4.
    2. plugins/unreal-kit/skills/unreal-domain/references/shared-runtime.md - the shared venv, project discovery, and the two execution channels all three skills depend on.
