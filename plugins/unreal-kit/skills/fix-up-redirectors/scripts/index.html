Unreal ObjectRedirector fix-up scripts that discover, classify, filter, and apply safe cleanup

This directory is the executable core of the fix-up-redirectors workflow. It turns a broad Unreal ObjectRedirector sweep into a P4-safe cleanup by separating discovery, safety triage, code-reference guarding, optional sampling, and the final mutation step.The scripts run in two environments: two Unreal commandlets read and mutate asset packages, while the host-side scripts inspect Perforce state and source-code references. That split is the main reason the directory is a six-stage pipeline rather than one monolithic tool.

Where to start

Open plugins/unreal-kit/skills/fix-up-redirectors/scripts/discover_redirectors.py first because it defines the discovery record that every later stage consumes: package, file, target existence, referencer packages, referencer files, and unresolved flags.
