Unreal ObjectRedirector fix-up scripts that discover, classify, filter, and apply safe cleanup

This directory holds the six scripts that run ObjectRedirector cleanup for an Unreal project under Perforce: they discover redirector assets, decide which ones are safe to remove, and then delete them in a single changelist with their referencers rewritten to point at the redirector targets. The scripts are a file-passing pipeline rather than one long program: a discovery YAML, then a safe-set JSON, then the mutation. The split exists because discovery and apply run inside an Unreal commandlet while the safety gates run in the host shell. The shape to keep in mind is fail-closed gating: every phase re-checks the on-disk state and refuses to proceed on ambiguity, so a run that stops early tells you which gate it stopped at.

Where to start

plugins/unreal-kit/skills/fix-up-redirectors/scripts/apply_fixups.py is the first open: its module docstring walks the entire apply flow, both run modes, and every guard, so it reads as the map for why the earlier phases exist. When a run comes back blocked or smaller than expected, plugins/unreal-kit/skills/fix-up-redirectors/scripts/classify_safety.py is the second read, because it is where redirectors get split into safe, blocked, orphaned, and broken buckets.

Routes

  • Full cleanup, discovery through apply
    1. plugins/unreal-kit/skills/fix-up-redirectors/scripts/discover_redirectors.py in Unreal
    2. plugins/unreal-kit/skills/fix-up-redirectors/scripts/classify_safety.py on the host
    3. plugins/unreal-kit/skills/fix-up-redirectors/scripts/filter_safe_by_code_refs.py on the host
    4. plugins/unreal-kit/skills/fix-up-redirectors/scripts/apply_fixups.py in Unreal
  • Trial a broad purge on a small slice
    1. plugins/unreal-kit/skills/fix-up-redirectors/scripts/classify_safety.py
    2. plugins/unreal-kit/skills/fix-up-redirectors/scripts/pick_one_per_dir.py reduces the safe set to one redirector per package directory
    3. plugins/unreal-kit/skills/fix-up-redirectors/scripts/apply_fixups.py on the reduced set
  • Refresh the code-reference cache
    1. plugins/unreal-kit/skills/fix-up-redirectors/scripts/scan_code_references.py writes the cache
    2. plugins/unreal-kit/skills/fix-up-redirectors/scripts/filter_safe_by_code_refs.py uses it before apply

Trial slices and the code-reference cache

  • plugins/unreal-kit/skills/fix-up-redirectors/scripts/pick_one_per_dir.py reduces a safe-set JSON to one redirector per package directory, a deterministic low-blast-radius trial for a broad purge. Run it between classification and apply when you want to verify the cleanup on a small slice first.
  • plugins/unreal-kit/skills/fix-up-redirectors/scripts/scan_code_references.py is the standalone scanner behind the code-reference cache the filter consumes. Run it when the cache is missing, stale, or was built against the wrong project root.
  • skills Unreal Engine automation skills providing Python data access, in-Editor MCP control, and P4-backed ObjectRedirector cleanup over a shared UE runtime.
  • SKILL.md The runbook for the fix-up-redirectors skill: the phase prompts that drive these scripts.
  • lib The shared modules these scripts import: record IO, Perforce calls, code-reference cache helpers, and package-to-file mapping.
