Reference docs for the Unreal Engine Python API skill: execution, bootstrap, setup, and asset patterns.

These are the reference docs that back the ue-python-api skill: working patterns and how-tos for driving Unreal Engine from Python, not a tutorial. They split into three jobs - how a script reaches the engine, how the environment sets itself up, and how to read and map project assets - with one doc that holds the whole model together. The code blocks are written to be pasted into a project and adapted, so most docs read as copy-out material. The documents point at each other, so a short one usually names the deeper one when a question goes past it.

Where to start

Open architecture.md first: it lays out the plugins the project needs, the two execution modes with the fallback rule between them, and what the session bootstrap installs, and it names the doc that answers each deeper question. If you came here to run or debug a script rather than understand the setup, start at script-execution.md instead.

Routes

  • First setup: project-setup.md -> bootstrapped-setup.md, then restart the editor so the ini flags take effect.
  • Run a script: architecture.md -> script-execution.md, from the mode table to the full capability split between editor and commandlet.
  • Dependencies inside the editor: script-bootstrap.md -> unreal-pip.md, the installer the bootstrap call shells out to.
  • Audit assets: asset-inspection.md -> reference-graph.md, from single-asset properties to whole-graph walks and orphan detection.

How the skill fits together

  • architecture.md - the whole-skill model: which plugins the project needs, the two execution modes and the fallback rule between them, and how API stubs resolve. Open it when a question cuts across the other docs.

Reaching the engine

  • script-execution.md - every way a script reaches the engine: editor console, menu, startup scripts, headless commandlet, and utility widgets, plus progress, logging, and output-file patterns and what does and does not work headless.
  • upyrc.md - the remote transport: how the host wrapper sends code to a running editor over UDP multicast and where it sits in the runner's execution path.
  • commandlet-safe-init.md - three guards that keep a project's startup init script quiet in commandlet mode, with the verification grep to confirm the noise is gone.

Setting up the environment

  • project-setup.md - what the session bootstrap does automatically on a first session, when interactive setup is needed, and the signs that setup failed.
  • bootstrapped-setup.md - the table of what bootstrap writes and where, plus the troubleshooting for config resolution, remote execution, and missing stubs.
  • script-bootstrap.md - the in-editor dependency split: how the ensure_dependencies call installs packages into the engine's own Python and how that differs from the host venv.
  • unreal-pip.md - the package manager the in-editor bootstrap calls: the small API, where installed packages land, and the Windows-only caveat.

Reading and mapping assets

  • asset-inspection.md - reading one asset: nested struct properties, property discovery, class hierarchy, Blueprint defaults, soft references, subobjects, and JSON export.
  • reference-graph.md - walking the asset registry's reference graph: dependency and referencer trees, cross-references between two asset sets, cycles, and orphan audits.
  • animation-patterns.md - ready-to-copy recipes for animation assets: listing clips, montage and blueprint inspection, TMap-based emote sets, and mapping a skeleton to its animations.
