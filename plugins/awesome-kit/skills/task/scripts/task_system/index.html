The task-system implementation: the typed-unit schemas, task type registry and reference resolution backing the task CLI verbs, plus the discovery, validation, list and review logic those verbs share.

This package is the working implementation behind the task CLI. It keeps the typed-unit rules, the single task type, reference rules, and the shared logic that the verbs use. It keeps one source of truth for task shape, status, and location checks.

Where to start

plugins/awesome-kit/skills/task/scripts/task_system/__init__.py first: it names the package's contract and the spec it follows. Then choose a verb module by the action you are changing.

Typed units and task type

  • plugins/awesome-kit/skills/task/scripts/task_system/schemas.pySchema floors for task.yaml, task_list, and task_items blocks.
  • plugins/awesome-kit/skills/task/scripts/task_system/types.pyThe registered hand-off type: statuses, priorities, scaffolding, and closure notes.
  • plugins/awesome-kit/skills/task/scripts/task_system/task_items.pyReads and checks the plan.md item block and stale priority refs.

References and locations

  • plugins/awesome-kit/skills/task/scripts/task_system/resolve.pyCanonicalizes refs to tmp or dev/tasks paths and finds parking spots.
  • plugins/awesome-kit/skills/task/scripts/task_system/reference_rewrite.pyMove logic and span-accurate rewrite of task_list references.
  • plugins/awesome-kit/skills/task/scripts/task_system/location_ops.pyArchive, delete, and VCS-aware folder disposition.

Discovery and review

  • plugins/awesome-kit/skills/task/scripts/task_system/discovery.pyFinds live tasks from folders and embedded references, with skip notes.
  • plugins/awesome-kit/skills/task/scripts/task_system/listing.pyProjects records into list/review rows, sections, projects, and diagnostics.
  • plugins/awesome-kit/skills/task/scripts/task_system/review_html.pyRenders the self-contained review page from listing data.
  • plugins/awesome-kit/skills/task/scripts/task_system/summary_ops.pyGenerates one-line summaries and writes them through the shared state path.

State verbs

  • plugins/awesome-kit/skills/task/scripts/task_system/init.pyScaffolds a valid active folder and removes it if validation fails.
  • plugins/awesome-kit/skills/task/scripts/task_system/state_ops.pyWork, update, close, and reopen with shared task.yaml edits and log entries.
  • plugins/awesome-kit/skills/task/scripts/task_system/validate.pyClassifies a task and emits errors, warnings, and advisory notes.
