Task skill reference documents for communication, hand-off authoring, and triage

These documents define how a task folder carries work across sessions and how the agent should communicate at the end of a turn. The set is organized by job: shared vocabulary, folder authoring, a populated example, and a triage procedure. Most readers start with the shared vocabulary, then move to the authoring contract, and use the triage protocol when open tasks need review.

Where to start

plugins/awesome-kit/skills/task/references/communication-framework.md is the first stop, because the other documents use its terms for work units, end-of-turn state, hand-off batons, and on-demand context.

plugins/awesome-kit/skills/task/references/handoff-template.md is the next stop when the reader is filling or updating a task folder, and plugins/awesome-kit/skills/task/references/example-claude-md.md is the concrete shape to compare against.

Routes

  • Author or refresh a task folder
    1. plugins/awesome-kit/skills/task/references/communication-framework.md
    2. plugins/awesome-kit/skills/task/references/handoff-template.md

  • Apply a triage ruling
