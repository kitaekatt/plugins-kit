The awesome-kit task skill dispatch surface: the task.py CLI, file-backed task folder model, verb contracts, design specs, and task-system diagrams

Dispatch surface for the task system. A task is a file-backed folder. State lives in its YAML record, open items in its plan document, and references resolve by reading the folder. One CLI handles the verbs.

Start

Open plugins/awesome-kit/skills/task/SKILL.md for verb dispatch; if modeling, read plugins/awesome-kit/skills/task/design/task-system-design.md

Core files

  • plugins/awesome-kit/skills/task/SKILL.md dispatch contract and agent-side behaviors.
  • plugins/awesome-kit/skills/task/scripts/task.py single CLI entry: verb subcommands, findings to stderr, results to stdout.
  • plugins/awesome-kit/skills/task/scripts/bootstrap_guard.py stdlib-only guard re-execs under venv; actionable failure if bootstrap missing.
  • plugins/awesome-kit/skills/task/design/task-system-design.md full spec; code supersedes it.
  • plugins/awesome-kit/skills/task/design/task-items-design.md ratified item enumeration.
  • plugins/awesome-kit/skills/task/design/diagrams/task-lifecycle.html lifecycle states and operations.
  • plugins/awesome-kit/skills/task/design/diagrams/task-entities.html entities, cardinalities, invariants.
  • plugins/awesome-kit/skills/task/design/diagrams/task-work-sequence.html work sequence: resolve, validate, emit.
  • plugins/awesome-kit/skills/task/design/diagrams/task-discovery.html list scope, discovery, resolve, dedupe.
  • plugins/awesome-kit/skills/task/design/diagrams/task-move.html move location and reference rewrites.
  • plugins/awesome-kit/skills/task/design/diagrams/task-discovery.dataflow.json dataflow source for discovery.
  • plugins/awesome-kit/skills/task/design/diagrams/task-work-sequence.sequence.json sequence source for work.
  • skills awesome-kit skills: the debug-context, recap, and verbose-updates interaction skills plus the plugin-ecosystem poster generator
  • references Task skill reference documents for communication, hand-off authoring, and triage
  • task_system The task-system implementation: the typed-unit schemas, task type registry and reference resolution backing the task CLI verbs, plus the discovery, validation, list and review logic those verbs share.
