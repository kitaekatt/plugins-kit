awesome-kit skills: session-interaction skills (debug-context, recap, verbose-updates), the task-folder system with its 14-verb CLI and design diagrams, and the plugin-ecosystem poster generator

This is the skills directory of the awesome-kit plugin, and each capability lives in its own folder. Most are a single SKILL.md: the procedure the agent follows, with no code beside it. Three shape how the agent talks with you: answering questions about its own behavior on the spot, distilling a too-long turn into what got done, and reporting progress while you are away from the conversation. A fourth renders your installed plugin ecosystem as a 16:9 poster page. The rest of the weight is a file-backed work-tracking system: a 14-verb command line over task folders, with its design documents and diagrams beside it.

Where to start

Start with plugins/awesome-kit/skills/task/SKILL.md. It routes a natural-language work request to the CLI's 14 verbs and states what the agent, rather than the script, must do with each output; everything else here is either a self-contained procedure or support for that system.

Routes

  • Work a task
    1. plugins/awesome-kit/skills/task/SKILL.md
    2. plugins/awesome-kit/skills/task/scripts/task.py
    3. work <ref>
    4. invoke each emitted Skill line, then hand implementation to the orchestrate skill
  • Gate work on findings
    1. plugins/awesome-kit/skills/task/scripts/task.py
    2. validate <ref>
    3. errors and warnings both block; fix forward, then re-validate
  • Refresh the plugin poster
    1. plugins/awesome-kit/skills/plugin-ecosystem/SKILL.md
    2. plugins/awesome-kit/skills/plugin-ecosystem/scripts/generate.py
    3. renders one self-contained 16:9 page of the installed ecosystem and opens it
  • Read the task design
    1. plugins/awesome-kit/skills/task/design/task-system-design.md
    2. plugins/awesome-kit/skills/task/design/diagrams
    3. the five pictures beside the spec: lifecycle, entities, work sequence, discovery, move

Conversation discipline

  • plugins/awesome-kit/skills/debug-context/SKILL.md - answer a question about the agent's own behavior from context, marking each load-bearing claim established or hypothesis, then verify in the background.
  • plugins/awesome-kit/skills/recap/SKILL.md - the recap procedure: what got done plus the genuinely blocking decisions, in as few lines as the content allows; one batched interview only on a contentless reply.
  • plugins/awesome-kit/skills/verbose-updates/SKILL.md - the three-part end-of-turn update for a context-switched user: what changed, where it sits, and the one required action.

The plugin-ecosystem poster

  • plugins/awesome-kit/skills/plugin-ecosystem/SKILL.md - when to generate the poster, how user phrasings map to flags, and the four-party data model behind each plugin badge.
  • plugins/awesome-kit/skills/plugin-ecosystem/scripts/generate.py - the stdlib-only generator: one self-contained 16:9 page, reading machine state unless its flags redirect the inputs to a source tree.

The task system

  • plugins/awesome-kit/skills/task/SKILL.md - dispatch surface: routes a natural-language request to a CLI verb and states what the agent must do with each output.
  • plugins/awesome-kit/skills/task/scripts/task.py - the CLI: 14 verbs over task folders, with its output conventions and the venv re-exec before any import.
  • plugins/awesome-kit/skills/task/scripts/bootstrap_guard.py - the vendored, stdlib-only guard that detects an unprovisioned plugin venv and re-execs under it.
  • plugins/awesome-kit/skills/task/scripts/task_system - the 14 modules behind the verbs: discovery, validation, listing, state and location ops, item parsing, and the review-page renderer.
  • The hand-off template, communication framework, and triage documents are on the references page; work dispatches implementation to the orchestrate skill, which has its own page.

Task design

  • plugins/awesome-kit/skills/task/design/task-system-design.md - the v1 spec: entities, states, per-verb contracts, and the closure policy. Where it and the code disagree, the code wins.
  • plugins/awesome-kit/skills/task/design/task-items-design.md - the ratified design for the open-item block: why it lives in the plan document, and what it deliberately does not add.
  • plugins/awesome-kit/skills/task/design/diagrams - five static diagrams for lifecycle, entities, work sequence, discovery, and move, with two JSON sources; open them in a browser.
  • The observed evidence behind the item design is kept in the repository's planning documents, not shipped with the plugin.
  • plugins The Claude Code plugin marketplace: independently installable plugins sharing the bootstrap provisioning engine and llm-scripting-kit access layer, covering code review, durable job execution, LLM endpoint dispatch, Hue scene synchronization, PDF rendering, fleet secrets provisioning, prompt statusline, cache forensics, markdown auditing, and Unreal Engine automation.
  • orchestrate The orchestrate skill that delegates implementation units to background agents: its procedure, shipped routing policy, the per-machine policy renderer, and the dispatch and configuration references
  • references Task skill reference documents for communication, hand-off authoring, and triage
  • awesome-kit The awesome-kit plugin root: plugin manifest and marketplace metadata, one level above the skills directory.
