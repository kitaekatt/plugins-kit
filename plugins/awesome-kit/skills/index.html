awesome-kit skills: the debug-context, recap, and verbose-updates interaction skills plus the plugin-ecosystem poster generator

This is the skills half of the awesome-kit plugin: three conversation protocols and one poster generator. The three protocols answer the questions a user asks mid-session: why the agent did something while present, what a long turn just accomplished, and where a context-switched user stands at each turn's end. Each protocol is one markdown file the agent loads on demand, so the whole behavior reads top to bottom. The generator is different in kind: it is a skill with a script that renders the installed marketplaces and plugins into a 16:9 poster you open in a browser.

Where to start

For the poster, open plugin-ecosystem/SKILL.md first: it holds the data model and the flags that keep a published page from describing the machine that built it. For the conversation protocols, open recap/SKILL.md: the shortest of the three, and its distill-then-interview shape shows how the other two are built.

Routes

  • Refresh the personal poster: plugin-ecosystem/SKILL.md -> plugin-ecosystem/scripts/generate.py. The script overwrites the poster file and opens it in a browser.
  • Build a marketplace landing page: the flag block in plugin-ecosystem/SKILL.md -> plugin-ecosystem/scripts/generate.py with --marketplace and the redirecting flags, so the page describes the repo, not the build machine.
  • Track a wrong badge: the five-step state precedence in plugin-ecosystem/SKILL.md -> compute_state in plugin-ecosystem/scripts/generate.py; the function's docstring restates the same order.

Conversation protocols

  • debug-context/SKILL.md -- answer-first procedure for the present user: no tool call before the answer, each load-bearing claim marked established or hypothesis, then background gatherers reconcile against the answer already given. Open it when why-did-you questions stall in foreground hunting.
  • recap/SKILL.md -- the /recap handler: what got done plus the genuinely blocking decisions, terse text only, and a batched interview only after a contentless reply. Open it when recaps run long, interview too early, or re-ask settled questions.
  • verbose-updates/SKILL.md -- the three-part end-of-turn template (What changed, Where it sits, Required user action) for a user who reads only turn-end messages, with argument-based modes such as strategy. The longest of the three; its shared glossary is defined one level down, so use the task card to reach the definitions.

Poster generator

  • plugin-ecosystem/SKILL.md -- the poster data model: the marketplace opt-in gate, who owns each field on the poster, and the five-step badge precedence. Open it before editing poster copy, adding a marketplace, or changing the title or tagline.
  • plugin-ecosystem/scripts/generate.py -- the stdlib-only generator: reads the registry, manifests, and settings, drops phantom installs and hidden plugins, and emits one self-contained HTML file. Open it when a badge, filter, or column renders wrong.
