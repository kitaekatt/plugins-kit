The llm-scripting-kit package that resolves credentials, endpoints, models, reachability, quota pacing, and completion backends for configured model calls.

This package is the shared layer that every plugin in this kit uses when it makes a configured model call. A caller names a model or endpoint by id, and the package answers what this machine can actually do: which credentials resolve, which servers answer, which subscription windows still have budget, and which backend can dispatch the work. It is stdlib-only by default, and the few places that reach for optional dependencies import them lazily. Everything a user configures lives in layered files outside this directory, so the code here reads configuration rather than owning it.

Where to start

Open cli.py to read every subcommand and exit code the package promises from a terminal. __init__.py is the import surface when you call the package from Python.

Routes

  • Store a key: cli.py set-key -> env_file.py -> api_key.py
  • Verify an endpoint: cli.py endpoints --verify -> reachability.py -> account.py
  • Render a declaration: cli.py describe -> declaration.py (reads usage_budget.py and reachability.py)
  • Run a completion: cli.py complete -> request_protocol.py -> completion/

The command line

cli.py
Every subcommand: status, set-key, endpoints, probe, describe, usage, seats, models, resolve, complete. The exit codes split a failed call from bad input, so a caller can tell what to retry. Open it first when a command misbehaves.
request_protocol.py
The versioned JSON request behind complete --request-file, so a machine consumer has one surface instead of a flag wall. Read it when you send requests from outside Python.
review_lane.py
Runs one code-review lane against a configured endpoint and refuses loudly instead of falling back to another reviewer. Open it when a review dispatch is refused.

Credentials

api_key.py
Resolves an endpoint's key through five layers, from environment variable to configured key file, and says which one won. Open it when a key comes from the wrong place.
account.py
Checks a key against the auth check an endpoint declares, and pings the models endpoint without ever raising. Open it to see how a credential verdict becomes a value, not an exception.
client.py
Builds an OpenAI client for any endpoint, importing the SDK only when asked and sending a stand-in key to keyless servers. Open it when you construct a client from Python.
constants.py
The default endpoint's values and the canonical credential-file locations, including the superseded project path. Open it to find where credential files live.
env_file.py
The reader and writer for the plugin's small credential files: quotes a value only when needed and creates the file at 0600. Open it when a credential file is malformed or world-readable.

Configuration

default_config.yaml
The shipped baseline: named endpoints, model aliases, and the default and defaultCheap selectors, with the layering rules in the comments on top. Read it to see what every machine gets before overrides.
models.py
Resolves a model name or endpoint to a concrete slug and base URL by deep-merging the shipped baseline under the fleet, machine, and project layers. Open it when a name resolves to something you did not expect.
model_endpoints.py
Reads the user-owned registry of machine-specific endpoints, a YAML file outside this package. Open it when an entry id resolves from a file you do not see here.

Availability

reachability.py
Answers whether a configured endpoint answers right now, with three verdicts: reachable, unreachable, unknown. A check that could not run is never reported as down, and no completion is ever sent. Open it when a verdict says unknown.
usage_budget.py
The third axis: whether a subscription window still has budget, from files the harnesses already wrote. A spent pool disables a model; one merely behind pace only de-prioritizes it. Open it when a paced model is missing or ordered last.
seats.py
Finds reachable harness seats UP and BESIDE a given model, using the reachability and quota verdicts. Open it when you choose a stronger or independent model for a unit of work.

Selection and dispatch

declaration.py
The one API over a model declaration: describe renders what this machine can run in pace order, run dispatches it, and the floor itemizes every entry when none is usable. Open it when a declaration fails.
harness_adapters.py
Builds the argv for a codex or opencode dispatch, leaving the brief on stdin. Read it before you change how a harness is invoked or its effort menu.

The completion seam

completion/
13 modules making one complete() protocol run over four transports: the OpenRouter HTTP endpoint and the claude, codex, and opencode CLIs. Open completion/halt.py for the halt taxonomy every backend reports, completion/types.py for the shared types, and completion/backends.py for the transports.

Package root

__init__.py
The import surface: every name a consumer takes from this package is re-exported here, so the export list maps the package. Open it when you add a public name or look up where one lives.
