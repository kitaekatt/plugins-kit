The llm-scripting-kit library that configures, verifies, and dispatches LLM model calls across OpenAI-compatible servers and CLI harnesses, with layered credential resolution, reachability checks, and subscription quota pacing.

This library resolves one LLM dispatch: choose a model and endpoint, resolve a credential, probe reachability, then run a completion over OpenAI-compatible HTTP or the claude, codex, and opencode CLI harnesses. Configuration layers let fleet, machine, and project settings override in turn. Probes avoid spending quota.

Where to start

Start with plugins/llm-scripting-kit/lib/llm_scripting_kit/__init__.py for the public API, then plugins/llm-scripting-kit/lib/llm_scripting_kit/cli.py for the command surface.

Routes

  • Dispatch a completion
    1. plugins/llm-scripting-kit/lib/llm_scripting_kit/declaration.py selects usable entries.
    2. plugins/llm-scripting-kit/lib/llm_scripting_kit/completion/factory.py builds the backend.
    3. plugins/llm-scripting-kit/lib/llm_scripting_kit/completion/backends.py executes the transport.
  • Resolve a credential
    1. plugins/llm-scripting-kit/lib/llm_scripting_kit/api_key.py walks precedence layers.
    2. plugins/llm-scripting-kit/lib/llm_scripting_kit/constants.py names key file locations.
    3. plugins/llm-scripting-kit/lib/llm_scripting_kit/env_file.py parses KEY=VALUE files.
  • Probe reachability
    1. plugins/llm-scripting-kit/lib/llm_scripting_kit/cli.py exposes probe and verify.
    2. plugins/llm-scripting-kit/lib/llm_scripting_kit/reachability.py returns reachable, unreachable, or unknown.
    3. plugins/llm-scripting-kit/lib/llm_scripting_kit/account.py sends a bounded models-endpoint ping.
  • Resolve a model
    1. plugins/llm-scripting-kit/lib/llm_scripting_kit/models.py resolves aliases to provider slugs.
    2. plugins/llm-scripting-kit/lib/llm_scripting_kit/default_config.yaml is the shipped baseline.
    3. plugins/llm-scripting-kit/lib/llm_scripting_kit/model_endpoints.py reads user-owned named endpoints.

Public surface

  • plugins/llm-scripting-kit/lib/llm_scripting_kit/__init__.py re-exports the public API, with openai and bootstrap_lib lazy.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/cli.py carries status, set-key, endpoints, probe, usage, describe, seats, models, resolve, repair-json, complete, frontdoor, and swapper.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/request_protocol.py is the versioned JSON request half of complete.

Completion transports

  • plugins/llm-scripting-kit/lib/llm_scripting_kit/completion/contract.py shapes the answer; plugins/llm-scripting-kit/lib/llm_scripting_kit/completion/halt.py classifies halts.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/client.py is a lazy openai client for named endpoints.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/harness_adapters.py defines codex and opencode command grammar.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/effort.py shares reasoning-effort vocabulary.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/observer.py receives execution events from run().

Front door and swapper

  • plugins/llm-scripting-kit/lib/llm_scripting_kit/frontdoor/server.py routes a model group across deployments.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/frontdoor/acceptance.py validates inbound bodies.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/swapper.py lists and terminates resident models.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/_swapper_process.py re-checks identity before signals.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/swapper_acceptance.py is the swapper acceptance module.

Supporting seams

  • plugins/llm-scripting-kit/lib/llm_scripting_kit/bootstrap_guard.py re-execs under the provisioned venv.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/seats.py finds reachable harness seats.
  • plugins/llm-scripting-kit/lib/llm_scripting_kit/review_lane.py runs review-lane dispatch.
