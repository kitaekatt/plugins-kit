The .workflow.yaml compiler and node-strategy infrastructure (script and OpenRouter runners) that extends the native Workflow tool with file-passing payloads and typed artifacts

A compiler and node-strategy layer for Claude Code's native Workflow tool. A human authors a durable workflow as declarative YAML; this plugin validates it and emits a native script the Workflow tool executes, without reimplementing execution. Node strategies add deterministic script nodes and non-Claude model calls that keep payloads on disk via a file-passing contract, so large data bypasses the model context. The core is a small Python package; a skill and its references carry the authoring and running procedures.

Where to start

Open plugins/workflow-kit/skills/workflow-kit/SKILL.md for the task-specific reference index; it routes you to the right reference for authoring, compiling, running, or wiring node strategies. For the ten-second shape, the plugins/workflow-kit/README.md is shorter.

Routes

  • Author and run a workflow
    1. Write a *.workflow.yaml (see plugins/workflow-kit/examples/review-changes.workflow.yaml for the format).
    2. Compile with plugins/workflow-kit/scripts/compile_workflow.py via the plugin-venv interpreter.
    3. Pass the compiled path to the native Workflow tool; the skill's run procedure handles reserved args.
  • Wire a node strategy by hand
    1. Paste plugins/workflow-kit/skills/workflow-kit/references/preamble.js into a native Workflow script (it cannot import).
    2. Call wkScript or wkOpenRouter; the plugins/workflow-kit/agents/workflow-kit-agent.md executor runs the command and returns metadata.
  • Add a typed artifact
    1. Declare provides in a script or openrouter step (see plugins/workflow-kit/examples/typed-contracts.workflow.yaml).
    2. The compiler inlines plugins/workflow-kit/skills/workflow-kit/references/preamble-contracts.js and emits the guard.
    3. At run time plugins/workflow-kit/scripts/check_artifact.py or plugins/workflow-kit/scripts/openrouter_run.py writes the verdict file; a failed check stops the workflow.

Compile a workflow

  • plugins/workflow-kit/workflow_kit_lib/loader.py -- reads and parses a .workflow.yaml into a validated document.
  • plugins/workflow-kit/workflow_kit_lib/model.py -- the typed in-memory model: steps, pipelines, schemas, artifact specs; all validation lives here.
  • plugins/workflow-kit/workflow_kit_lib/compiler.py -- emits the native JS script (agent calls, pipelines, node-strategy inlining).
  • plugins/workflow-kit/workflow_kit_lib/expr.py -- the {{ }} expression mini-language compiled to live JS.
  • plugins/workflow-kit/workflow_kit_lib/contracts.py -- the provides/requires artifact checks (order, compatibility, schema digest).
  • plugins/workflow-kit/workflow_kit_lib/declarations.py -- model-declaration parsing and agent-step routing through the Claude core ids.
  • plugins/workflow-kit/scripts/compile_workflow.py -- the CLI: validate-only or compile to a .js file.

Run a node

  • plugins/workflow-kit/scripts/openrouter_run.py -- one non-Claude model call via llm-kit's declaration API; writes the reply to $OUT.
  • plugins/workflow-kit/scripts/check_artifact.py -- judges a script node's $OUT against its declared type; writes the verdict file.
  • plugins/workflow-kit/scripts/bootstrap_guard.py -- vendored stdlib-only guard that re-execs under the plugin venv; must run before any shared-lib import.

Author with the skill

  • plugins/workflow-kit/skills/workflow-kit/SKILL.md -- the task index; load the reference that matches your job.
  • plugins/workflow-kit/skills/workflow-kit/references/workflow-yaml.md -- the .workflow.yaml format, compile/run/scaffold procedures, and the typed-artifact contract.
  • plugins/workflow-kit/skills/workflow-kit/references/contract.md -- the node contract: file-passing via $OUT and $STATUS, the return schema, the verdict file.
  • plugins/workflow-kit/skills/workflow-kit/references/node-strategies.md -- the script and openrouter strategies, command templates, execution events, and model selection.
  • plugins/workflow-kit/skills/workflow-kit/references/preamble.js -- inlinable JS helpers (wkNode, wkScript, wkOpenRouter) for hand-written node scripts.
  • plugins/workflow-kit/skills/workflow-kit/references/preamble-contracts.js -- typed-artifact provider helpers (wkProviderFlags, wkScriptProvided, wkProvided); paste after preamble.js.

The executor

  • plugins/workflow-kit/agents/workflow-kit-agent.md -- the haiku agent that runs one shell command and returns metadata; never reads $OUT. Invoked by agentType; not auto-selected.

Examples

  • plugins/workflow-kit/examples/node-strategies.workflow.yaml and plugins/workflow-kit/examples/node-strategies.example.js -- the same three-node shape (script + openrouter + Claude reasoning) as a declarative YAML and a hand-written script.
  • plugins/workflow-kit/examples/review-changes.workflow.yaml -- a pipeline with parallel fan-out over dimensions, each verified adversarially.
  • plugins/workflow-kit/examples/typed-contracts.workflow.yaml -- provides/requires with a schema-typed artifact and an opaque-file artifact.
  • plugins/workflow-kit/examples/scripts/wordcount.py -- the tiny deterministic script the examples call; stdlib-only.

Install and provision

  • plugins/workflow-kit/.claude-plugin/plugin.json -- plugin metadata, version, keywords, and the bootstrap dependency.
  • plugins/workflow-kit/bootstrap.json -- what bootstrap installs (llm-kit, uv), what it links (bootstrap_lib), and the venv check imports.
  • plugins/workflow-kit/pyproject.toml -- Python package config: pyyaml, katsoft-llm-kit[config,sdk], katsoft-contracts.
