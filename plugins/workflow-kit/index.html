The .workflow.yaml compiler and node-strategy infrastructure (script and OpenRouter runners) that extends the native Workflow tool with file-passing payloads and typed artifacts

This plugin adds declarative workflow authoring and two node strategies to Claude Code's native Workflow tool. A human writes a durable workflow in YAML, a deterministic compiler validates it and emits a native script, and node runners let deterministic commands and non-Claude model calls pass payloads by file instead of through model context. The directory is organized around that split: a Python compiler package, command-line runners, skill references, and small examples. Everything runs on the native Workflow tool; workflow-kit does not replace execution.

Where to start

plugins/workflow-kit/README.md first for the one-page model. Open plugins/workflow-kit/skills/workflow-kit/references/workflow-yaml.md when authoring, validating, or compiling a workflow document.

Routes

  • Validate a workflow document
    1. plugins/workflow-kit/scripts/compile_workflow.py with validate-only mode on a workflow YAML file
  • Compile a workflow for the native Workflow tool
    1. plugins/workflow-kit/scripts/compile_workflow.py with an output JavaScript file, then pass the emitted path as scriptPath to the native Workflow tool
  • Check a typed script artifact
    1. plugins/workflow-kit/scripts/check_artifact.py with artifact name, kind, input file, verdict file, and expected command exit
  • Add node helpers to a hand-written script
    1. plugins/workflow-kit/skills/workflow-kit/references/preamble.js plugins/workflow-kit/skills/workflow-kit/references/preamble-contracts.js use the second only when a node provides a typed artifact

Compiler and model

  • plugins/workflow-kit/scripts/compile_workflow.py CLI that validates a workflow YAML document and compiles it to a native Workflow script; use for validate-only or emitting JavaScript.
  • plugins/workflow-kit/workflow_kit_lib The Python package behind the CLI: eight modules for loading, validating, expression compilation, contract analysis, and code emission.
  • plugins/workflow-kit/workflow_kit_lib/compiler.py Where YAML steps become agent(), parallel(), and pipeline() calls plus node-strategy calls; open for emitted-script behavior.
  • plugins/workflow-kit/workflow_kit_lib/model.py The typed document model and step grammar; open for accepted keys and validation rules.
  • plugins/workflow-kit/workflow_kit_lib/contracts.py Typed artifact provides and requires checks; open for schema compatibility, ordering, and cardinality errors.
  • plugins/workflow-kit/workflow_kit_lib/expr.py The expression grammar compiled to live JavaScript; open for template and unknown-reference errors.
  • plugins/workflow-kit/workflow_kit_lib/loader.py YAML entry point that reads and validates a workflow file.
  • plugins/workflow-kit/workflow_kit_lib/errors.py The single WorkflowError type returned to authors.
  • plugins/workflow-kit/workflow_kit_lib/declarations.py Model declaration validation and agent-step routing to Claude core ids.

Node execution

  • plugins/workflow-kit/scripts/openrouter_run.py Runs one non-Claude model call for an openrouter node and writes the reply to OUT; open for model declaration, events, and artifact flags.
  • plugins/workflow-kit/scripts/check_artifact.py Judges a script node's OUT against its declared type and writes the verdict file; open for verdict and event behavior.
  • plugins/workflow-kit/agents/workflow-kit-agent.md The haiku executor that runs one shell command and returns metadata without reading OUT; open to see the node contract.

Authoring references

  • plugins/workflow-kit/skills/workflow-kit/references/workflow-yaml.md The workflow YAML v1 format and compile, validate, and run procedures; the main authoring reference.
  • plugins/workflow-kit/skills/workflow-kit/references/contract.md The file-passing node contract and why payloads travel by file; open for OUT, STATUS, and verdict semantics.
  • plugins/workflow-kit/skills/workflow-kit/references/node-strategies.md How to wire script and openrouter nodes, including hand-written commands and typed providers.
  • plugins/workflow-kit/skills/workflow-kit/references/preamble.js The helpers to paste into a hand-written native Workflow script for node strategies.
  • plugins/workflow-kit/skills/workflow-kit/references/preamble-contracts.js Provider helpers to paste after the base helpers when a node provides a typed artifact.

  • plugins/workflow-kit/examples/node-strategies.workflow.yaml A declarative script and openrouter node example that feeds one reasoning node.
