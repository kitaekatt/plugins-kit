md-domain skill workflow scripts for fan-out detect, classify, generate, and remediate phases

Ten workflow scripts live here: eight fan-out audit lanes and the two-lane pipeline that assesses and writes the agent-guidance corpus. Each script is a lane dispatcher: it takes a list of targets from the skill's main loop, spawns one isolated agent lane per file, and returns a structured per-file result for the main loop to render. The detect and classify lanes are read-only by contract; they return findings and never edit, which is what lets an audit be re-run and reproduce the same findings. The remediate lanes run after the Q&A gate and apply only the edits the gate decided. The generation lane is the one phase that cannot fan out freely, because a parent document is composed from its children's finished documents, so it runs wave by wave, deepest first.

Where to start

Start with claude-md-remediate.js: at five kilobytes it is the shortest script, and it is the whole lane pattern, arguments in, one agent per file, a result schema, a summary out. Read a detect script against it when you want to see where the added complexity lands: criteria loading, review mode, batching.

Routes

  • Audit agent-guidance files: claude-md-detect.js -> the Q&A gate -> claude-md-remediate.js
  • Audit skill contracts: skill-detect.js -> the Q&A gate -> skill-remediate.js
  • Audit project documents: project-doc-detect.js -> the Q&A gate -> project-doc-remediate.js
  • Fix cross-reference findings: scanner run -> references-classify.js -> the Q&A gate -> references-remediate.js
  • Write the guidance corpus: coverage-detect.js report -> claude-md-generate.js, wave by wave, deepest first

Agent-guidance audits

claude-md-detect.js
The detect lane: one isolated agent per target file, applying the criteria, running the mechanical validator, and classifying every finding into a taxonomy and a disposition bucket. Open it for the finding schema, the review-mode attributability check, or the decline contract for a file outside the audit subject.
claude-md-remediate.js
The after-gate pass: one lane per file, applying the approved edits in order and reporting applied, skipped, and failed. Open it to see the lane-pinning pattern or to change how an approved edit lands.

Skill-contract audits

skill-detect.js
Audits the skill's contract file and its reference documents, choosing the criteria set from the path shape when the caller supplies no classification. Open it for the two-subject split, the mechanical-validator wiring, or the shape test a kind-less call runs itself.
skill-remediate.js
Applies the approved edits to a contract file, including the two taxonomies whose fix touches a sibling file instead. Open it when an approved fix reaches outside the file being audited.

Project-document audits

project-doc-detect.js
Audits standalone project documents against the placement and cohesion criteria, using the citation and size signals a discovery script precomputed. Open it for the orphan rule, the size threshold, or the structural-move dispositions.
project-doc-remediate.js
Applies the approved edits and structural moves, folding, relocating, or collapsing a document, while new-skill authoring is routed back to the main loop. Open it to change what a move is allowed to do.

Cross-reference audits

references-classify.js
Takes the scanner's per-file findings and assigns each a taxonomy category and a disposition, computing the exact before and after text for every auto-fix. Open it for the master razor that decides what an auto-apply may touch.
references-remediate.js
Applies the decided fixes: exact before-and-after replacements where the text is known, instruction-type edits where it is not, and a failed status where an anchor has moved. Open it to see how an edit reports failure instead of guessing.

Corpus assessment and generation

coverage-detect.js
Assesses code directories for the facts that belong in the guidance ambient to them; report-only, with no remediate lane by design. Open it for the batching math, the anchor-membership checks, or the two input modes with different provenance.
claude-md-generate.js
Writes the corpus wave by wave, deepest first: compose, verify each proposed hoist against exactly the files it named, then apply the survivors. Open it for the wave barrier and why flattening it into a plain parallel run reintroduces a silent defect.
