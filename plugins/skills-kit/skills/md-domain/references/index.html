Where to start

Start with the audit glossary. It names the vocabulary used by audit lanes. Then open the registry beside it when you need the checked rules. plugins/skills-kit/skills/md-domain/references/audit-framework.md plugins/skills-kit/skills/md-domain/references/audit-framework.yaml

    3. Run detect, then dispatch fixes.
  • Read what an audit means
    1. Read the glossary for shared vocabulary. plugins/skills-kit/skills/md-domain/references/audit-framework.md
    2. Cross terms against the registry. plugins/skills-kit/skills/md-domain/references/audit-framework.yaml
  • Tune the audit rules
    1. Read the tuning guide. plugins/skills-kit/skills/md-domain/references/configuring-standards.md
    2. Read the authoring guide for additive standards files. plugins/skills-kit/skills/md-domain/references/authoring-standards.md
  • Generate from code
    1. Read the placement spine. plugins/skills-kit/skills/md-domain/references/cohesion-principles.md
    2. Read the analysis lane and its boundaries. plugins/skills-kit/skills/md-domain/references/lanes/coverage-lane.md
