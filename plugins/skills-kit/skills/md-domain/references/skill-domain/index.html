Reference material for the skill-domain: type contracts, canonical vocabulary, structural patterns, schema fixtures, and audit tooling documentation.

This reference set documents how skills in this project are typed, contracted, structured, and audited. It separates canonical vocabulary from the per-type contracts, gives minimal schema examples, and describes the scripts that check or classify a skill main file. Open it when a skill feels inconsistent, when a new sub-domain needs a routing surface, or when audit output needs interpretation.

Where to start

plugins/skills-kit/skills/md-domain/references/skill-domain/glossary.md first, because the contract tables use its terms without redefining them. plugins/skills-kit/skills/md-domain/references/skill-domain/framework.md is the next stop for per-type requirements, audit procedure, and conditional-requirement grammar.
