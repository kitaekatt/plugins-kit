Python scripts implementing the md-domain skill's discovery, audit, validation, and reporting functions

This is the md-domain skill's script layer. It discovers the subjects each audit lane assesses, shares the project-root and VCS-ignore rules those scripts import, fans unattended project-doc work into job-kit, and reports skill inventory and references. Every script is stdlib-only, so shared rules live in one home rather than drifting across callers.

Where to start

Start with plugins/skills-kit/skills/md-domain/scripts/discover_coverage.py because it defines the coverage subject and pulls in the project-root and VCS-ignore substrate the rest of the directory reuses.

Routes

  • Audit project docs
    1. plugins/skills-kit/skills/md-domain/scripts/emit_audit_jobs.py fans project docs into one job-kit job each.
    2. plugins/skills-kit/skills/md-domain/scripts/evidence_pack.py inlines each doc's facts into the prompt.
    3. plugins/skills-kit/skills/md-domain/scripts/check_project_doc_audit.py rejects findings that cannot cite the standards.
  • Prepare and verify coverage
    1. plugins/skills-kit/skills/md-domain/scripts/coverage_subjects.py build serializes the JSONL slice.
    2. the lane returns its agent-attested report.
    3. plugins/skills-kit/skills/md-domain/scripts/coverage_subjects.py verify re-checks it before promotion.
  • Inventory skills
    1. plugins/skills-kit/skills/md-domain/scripts/report.py dispatches roster or hierarchy via the audit command.
    2. plugins/skills-kit/skills/md-domain/scripts/skill_hierarchy_report.py renders the HTML hierarchy.

Scripts

  • plugins/skills-kit/skills/md-domain/scripts/discover_coverage.py - Non-recursive coverage subject: the directory's direct code files plus the instruction-file chain that loads for it.
  • plugins/skills-kit/skills/md-domain/scripts/discover_composition.py - Wider composition set: code in the directory or beneath it, deciding which directories get a composed document.
  • plugins/skills-kit/skills/md-domain/scripts/discover_claude_md.py - Ambient instruction files visible from a working directory, tagged by role and code-directory dimension.
  • plugins/skills-kit/skills/md-domain/scripts/discover_project_doc.py - Standalone project documents for the project-doc lane, neither skill files, instruction files, nor skill references, plus orphan-citation scan.
  • plugins/skills-kit/skills/md-domain/scripts/discover_skill.py - Skill contract files and, with a references flag, documents under each skill for the skill-audit lane.
  • plugins/skills-kit/skills/md-domain/scripts/coverage_subjects.py - Build and verify verbs for the analyze lane's subject slice: JSONL serialization and re-check of the agent-attested report.
  • plugins/skills-kit/skills/md-domain/scripts/project_root.py - Version-control-agnostic project-root walk the discover scripts import, so Perforce and git resolve alike.
  • plugins/skills-kit/skills/md-domain/scripts/vcs_ignore.py - Batched query for whether project version control excludes a path, for git, p4, or neither.
  • plugins/skills-kit/skills/md-domain/scripts/emit_audit_jobs.py - Fans project docs into one job-kit job each, reads the lane's model slot, and attaches the evidence pack.
  • plugins/skills-kit/skills/md-domain/scripts/check_project_doc_audit.py - Acceptance contract: reads the job report on stdin and rejects any finding that cannot cite the standards.
  • plugins/skills-kit/skills/md-domain/scripts/evidence_pack.py - Facts about one audit subject and repository for the model, so it need not rediscover them; no rule violation is no finding.
  • plugins/skills-kit/skills/md-domain/scripts/report.py - Dispatcher for the Markdown roster and HTML hierarchy skill-audit reports, reached via the audit command.
  • plugins/skills-kit/skills/md-domain/scripts/skill_hierarchy_report.py - Interactive HTML hierarchy of discoverable skills, with frontmatter columns and per-type tooltips.
  • plugins/skills-kit/skills/md-domain/scripts/references_audit.py - Broken cross-reference scan: builds a skill dependency graph and reports references that do not resolve.
  • plugins The Claude Code plugin marketplace: independently installable plugins sharing the bootstrap provisioning engine and llm-scripting-kit access layer, covering code review, durable job execution, LLM endpoint dispatch, Hue scene synchronization, PDF rendering, fleet secrets provisioning, prompt statusline, cache forensics, markdown auditing, and Unreal Engine automation.
  • SKILL.md The md-domain skill contract for the lanes and subject shapes these scripts implement.
  • references The reference docs for the standards and lane definitions the audit scripts parse.
