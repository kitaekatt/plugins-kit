md-domain Python scripts that discover audit subjects, emit audit jobs, build evidence packs, check audit reports and skill references, and render skill reports

These scripts back the md-domain audit lanes. Discovery, job emission, evidence, checking, and reporting are separate jobs sharing one directory. Each entry below identifies one script in that directory.

Scripts

  • plugins/skills-kit/skills/md-domain/scripts/check_project_doc_audit.pyReads an audit report on stdin and rejects findings missing standards ids or a line.
  • plugins/skills-kit/skills/md-domain/scripts/coverage_subjects.pyBuilds and verifies line-addressed JSONL, then re-checks the attested report.
  • plugins/skills-kit/skills/md-domain/scripts/discover_claude_md.pyLists Claude guidance files and variants, tagged classic or code-directory.
  • plugins/skills-kit/skills/md-domain/scripts/discover_composition.pyNames directories that receive a composed document.
  • plugins/skills-kit/skills/md-domain/scripts/discover_coverage.pyDefines a coverage subject: one directory's direct code files plus project guidance above it.
  • plugins/skills-kit/skills/md-domain/scripts/discover_project_doc.pyFinds project docs and emits kind, provenance, and inbound citations.
  • plugins/skills-kit/skills/md-domain/scripts/discover_skill.pyLists SKILL.md files and, with references, their skill-owned references.
  • plugins/skills-kit/skills/md-domain/scripts/emit_audit_jobs.pyTurns project docs into one job-kit job each, with evidence packs and checker stamp.
  • plugins/skills-kit/skills/md-domain/scripts/evidence_pack.pyBuilds the deterministic six-section fact pack for one subject.
  • plugins/skills-kit/skills/md-domain/scripts/project_root.pyVCS-agnostic project-root walk used by discoverers.
  • plugins/skills-kit/skills/md-domain/scripts/references_audit.pyScans markdown for skill cross-references, reporting broken hard and soft refs.
  • plugins/skills-kit/skills/md-domain/scripts/report.pySkill-audit dispatch: markdown roster or interactive HTML by subcommand.
  • plugins/skills-kit/skills/md-domain/scripts/skill_hierarchy_report.pyHTML hierarchy backend imported by report.
  • plugins/skills-kit/skills/md-domain/scripts/vcs_ignore.pyAsks whether VCS excludes a path, batched, degrading outside git or p4.
  • skills The skills-kit skills that audit and produce markdown, encode insights, teach the materialized-output pattern, and review sessions for documentation updates
  • SKILL.md Skill behind these scripts.
