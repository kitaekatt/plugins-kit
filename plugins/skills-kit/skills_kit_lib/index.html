The skills-kit plugin library that validates, classifies, and audits skill documents against typed-unit schemas, with its shipped standards and lane-model configuration.

This library is the Python implementation behind skills-kit markdown auditing, classification, tagging, and typed-unit validation. It turns fenced YAML blocks in skill documents into typed units, checks those units against registered contracts, and emits per-row verdicts. A second layer resolves shipped and user-tuned criteria, while a smaller layer handles directory discovery, frontmatter parsing, and the binding to bootstrap skill material. The code follows the audit pipeline: readers produce units, contracts describe units, evaluators judge units, and defaults supply the criteria.

Where to start

plugins/skills-kit/skills_kit_lib/schema_registry.py, because it names every typed unit, its role, and its owner document. Follow to plugins/skills-kit/skills_kit_lib/audit.py when you need the row labels and verdicts that a skill audit emits.

Routes

  • Audit a skill document
    1. python -m skills_kit_lib.audit <target>
    2. plugins/skills-kit/skills_kit_lib/document_walker.py extracts fenced YAML blocks and recognized units.
    3. plugins/skills-kit/skills_kit_lib/schema_registry.py resolves the unit root to a contract.
    4. plugins/skills-kit/skills_kit_lib/schema_engine.py walks the contract and reports per-path failures.
    5. plugins/skills-kit/skills_kit_lib/audit.py combines universal, contract, and legacy rows into verdicts.
  • Classify an untagged skill
    1. python -m skills_kit_lib.classify <target>
    2. plugins/skills-kit/skills_kit_lib/document_walker.py detects contract roots when a parser is available.
    3. plugins/skills-kit/skills_kit_lib/markdown_heuristics.py scores narrative markers for legacy documents.
    4. plugins/skills-kit/skills_kit_lib/classify.py returns single-type, mixed-type, ambiguous, or indeterminate.
  • Trace a shipped criterion
    1. plugins/skills-kit/skills_kit_lib/standards_resolve.py merges shipped, user, and project layers.
    2. plugins/skills-kit/skills_kit_lib/rule_catalog.py separates architectural, optional, and inoffensive rule ids.
    3. plugins/skills-kit/skills_kit_lib/audit.py registers the mechanical evaluator for each criterion id.
    4. plugins/skills-kit/skills_kit_lib/defaults/standards/SKILL-standards.md states the shipped skill-document defaults.

Command entry points

  • plugins/skills-kit/skills_kit_lib/audit.py Runs deterministic contract checks on one skill document; open for verdict rows and thresholds.
  • plugins/skills-kit/skills_kit_lib/classify.py Infers a skill type from a YAML root or content shape; open for mixed-type or tag mismatches.
  • plugins/skills-kit/skills_kit_lib/tag.py Writes or checks a skill-type frontmatter value; open for idempotent tagging behavior.
  • plugins/skills-kit/skills_kit_lib/checks.py Runs corpus-level owner-document and member-reference checks; open for cross-file drift.

Document readers and discovery

  • plugins/skills-kit/skills_kit_lib/document_walker.py Extracts fenced YAML blocks and recognized typed units; open for block parsing behavior.
  • plugins/skills-kit/skills_kit_lib/markdown_heuristics.py Parses frontmatter and scores structural markers; open for legacy type signals.
  • plugins/skills-kit/skills_kit_lib/corpus.py Discovers skill documents across user, project, and plugin tiers; open for corpus queries.
  • plugins/skills-kit/skills_kit_lib/dirwalk.py Walks directories with a shared skip list; open for discovery pruning.
  • plugins/skills-kit/skills_kit_lib/instruction_files.py Resolves the active instruction file in a directory; open for precedence rules.
  • plugins/skills-kit/skills_kit_lib/material.py Binds to bootstrap skill material and exposes the material command; open for strict frontmatter or exit codes.

Typed-unit validation

  • plugins/skills-kit/skills_kit_lib/schema_engine.py Validates a parsed unit against a small rule DSL; open for the allowed rule keys.
  • plugins/skills-kit/skills_kit_lib/schema_registry.py Tracks typed-unit roots and roles; open for skill-type, portable, and instruction-file roots.
  • plugins/skills-kit/skills_kit_lib/rule_fragments.py Shares rule fragments for keywords, scope, facts, and steps; open for reusable shapes.
  • plugins/skills-kit/skills_kit_lib/schemas/skill_types.py Defines one contract per skill type; open for type-specific fields and forbidden keys.
  • plugins/skills-kit/skills_kit_lib/schemas/portable.py Defines portable units such as references, facts, area config, and actions; open for portable shapes.
  • plugins/skills-kit/skills_kit_lib/schemas/claude_md.py Defines the instruction-file contract; open for persistent instruction documents.
  • plugins/skills-kit/skills_kit_lib/schemas/standards.py Defines the standards-set contract; open for authored criteria blocks and severity enforcement.

Configured behavior

  • plugins/skills-kit/skills_kit_lib/standards_resolve.py Resolves layered standards configuration; open for disabled rules, thresholds, adapters, and audit settings.
  • plugins/skills-kit/skills_kit_lib/rule_catalog.py Catalogs configurable rule ids and buckets; open for disable checks and threshold consumers.
  • plugins/skills-kit/skills_kit_lib/lane_models.py Resolves lane model and effort entries; open for agent-routing and missing-effort findings.
  • plugins/skills-kit/skills_kit_lib/defaults/lane_models.yaml Ships the default lane model and effort list; open for shipped lane selection.
  • plugins/skills-kit/skills_kit_lib/defaults/standards/SKILL-standards.md Ships the skill-document criteria defaults; open for frontmatter, size, and floor rules.
  • plugins/skills-kit/skills_kit_lib/defaults/standards/SKILL-legacy-standards.md Ships legacy per-type heuristic criteria; open for pre-contract skill rows.
  • plugins/skills-kit/skills_kit_lib/defaults/standards/CLAUDE-md-standards.md Ships instruction-document criteria defaults; open for import size, body size, and record-floor rows.
