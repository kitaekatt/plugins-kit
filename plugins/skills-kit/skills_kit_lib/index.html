The skills-kit plugin library that validates, classifies, and audits skill documents against typed-unit schemas, with its shipped standards and lane-model configuration.

This is the Python library behind the skills-kit plugin's audit, classify, and tag commands. It validates skill and instruction documents against typed-unit schemas, resolves layered standards and lane-model configuration, and scores legacy skills that predate the YAML contract. The validation engine and its registered schemas form the core; per-skill CLI tools and corpus-level checks are the consumer surface on top.

Where to start

Open plugins/skills-kit/skills_kit_lib/__init__.py for the module map; its docstring names every subsystem and the registration-order constraint that makes import order matter.

Routes

  • Audit one skill
    1. python -m skills_kit_lib.audit <target> (see plugins/skills-kit/skills_kit_lib/audit.py) -- reads frontmatter, extracts YAML contract blocks, validates against the registered schema, and runs legacy heuristics only when no contract is present.
  • Run corpus checks
    1. python -m skills_kit_lib.checks [repo_root] -- validates owner-doc round-trip for every registered schema and resolves domain and capability member references across the repo.
  • Classify an untyped skill
    1. python -m skills_kit_lib.classify <target> -- detects a YAML contract root for a deterministic type, or falls back to heuristic scoring across the canonical type set.

Validation engine

  • plugins/skills-kit/skills_kit_lib/schema_engine.py -- rule-DSL validator; open when adding a rule type or debugging a pass/fail verdict.
  • plugins/skills-kit/skills_kit_lib/schema_registry.py -- registry of typed-unit roots and their schemas; open when registering a new unit type.
  • plugins/skills-kit/skills_kit_lib/rule_fragments.py -- composable rule building blocks (keywords, scope, fact-item, anti-pattern, technique-step) shared across schemas.
  • plugins/skills-kit/skills_kit_lib/document_walker.py -- extracts and parses fenced-YAML blocks; the one canonical fence regex for the plugin.

Schema definitions

  • plugins/skills-kit/skills_kit_lib/schemas -- four modules defining the registered schemas: skill-type (8 types), portable units (6), claude_md, and standards_set.

Per-skill CLI

  • plugins/skills-kit/skills_kit_lib/audit.py -- deterministic per-skill contract checks; the main audit entry point, invoked via python -m.
  • plugins/skills-kit/skills_kit_lib/classify.py -- two-path type inference: YAML contract root (deterministic) or heuristic score (legacy fallback).
  • plugins/skills-kit/skills_kit_lib/tag.py -- writes or replaces the skill-type frontmatter value; idempotent, refuses overwrite without --force.

Corpus and configuration

  • plugins/skills-kit/skills_kit_lib/checks.py -- corpus-level checks: owner-doc round-trip validation and domain/capability member-ref resolution.
  • plugins/skills-kit/skills_kit_lib/corpus.py -- SKILL.md discovery across user, project, and plugin tiers; the single source for the session's skill universe.
  • plugins/skills-kit/skills_kit_lib/standards_resolve.py -- layered standards config resolution (shipped, user, project); loud on malformed config, never a silent default.
  • plugins/skills-kit/skills_kit_lib/rule_catalog.py -- single source for every configurable rule id, its bucket (architectural, optional, inoffensive), and description.
  • plugins/skills-kit/skills_kit_lib/defaults/standards -- the three shipped standards files carrying the criteria plugins/skills-kit/skills_kit_lib/audit.py evaluates mechanically.

Heuristics and parsing

  • plugins/skills-kit/skills_kit_lib/markdown_heuristics.py -- structural-shape detectors and the one frontmatter parser for the plugin (light, full, and strict modes).
  • plugins/skills-kit/skills_kit_lib/material.py -- the sole binding to bootstrap_lib.skill_material; strict frontmatter mode and the material command for skill rendering.
  • plugins/skills-kit/skills_kit_lib/instruction_files.py -- resolves which instruction file ( plugins/skills-kit/skills_kit_lib/CLAUDE.md) is active in a directory.
  • plugins/skills-kit/skills_kit_lib/include_dirs.py -- shared --include-dir flag and environment-variable resolution for the md-domain discover scripts.

Lane dispatch

  • plugins/skills-kit/skills_kit_lib/lane_models.py -- resolves the layered lane_models slot and assigns each entry an agent or codex dispatch route.
  • plugins/skills-kit/skills_kit_lib/lane_bridge.py -- runs a lane on a codex harness entry through llm-kit dispatch; normalizes schemas for codex strict mode.
  • plugins/skills-kit/skills_kit_lib/defaults/lane_models.yaml -- shipped default model and effort per lane family (detect, classify, coverage, generate, remediate, audit_job).

Shared and package

  • plugins/skills-kit/skills_kit_lib/dirwalk.py -- depth-limited directory walk shared by the md-domain discover scripts; prunes noise and never follows symlinks.
  • plugins/skills-kit/skills_kit_lib/__init__.py -- package init; importing triggers schema registration, and order matters for modules that read the registry at load time.
