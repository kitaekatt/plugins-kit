The skills-kit plugin's scripts for bootstrap guarding, code generation, standards resolution, and command dispatch

These are the skills-kit plugin's runtime scripts. They fall into three jobs: guarding the bootstrap venv every plugin script depends on, generating lane workflow scripts and the standards documentation from their sources of truth, and dispatching md-domain audit lanes from config resolution through codex execution. The guard is vendored into sibling plugins and drift-checked; the generators are likewise drift-tested in CI so shipped output always matches the template.

Where to start

plugins/skills-kit/scripts/bootstrap_guard.py is the canonical vendored module every other script here imports before touching a shared library. Its re-exec contract explains why each script below re-execs into the plugin venv before its main import.

Routes

  • Regenerate lane scripts
    1. plugins/skills-kit/scripts/gen_workflow_js.py: edit the template or a per-lane fragment
    2. plugins/skills-kit/scripts/gen_workflow_js.py: run to rewrite the shipped .js files
    3. drift test asserts byte-identity between template output and the committed scripts
  • Regenerate standards doc
    1. edit rule_catalog.py or audit.py thresholds in the shared library
    2. plugins/skills-kit/scripts/gen_standards_doc.py: run to splice the generated region into the standards reference doc
    3. CI runs the same script with --check and fails on drift
  • Execute a codex lane
    1. plugins/skills-kit/scripts/resolve_standards.py: resolves the layered standards config and lane models to JSON
    2. the md-domain workflow script reads that JSON and dispatches each lane
    3. plugins/skills-kit/scripts/run_lane.py: executes the codex entry under the plugin venv via the lane bridge

Bootstrap guard and venv re-exec

plugins/skills-kit/scripts/bootstrap_guard.py -- the vendored canonical module. Provides require_bootstrap() (exit with an actionable message when bootstrap has not provisioned the plugin) and reexec_under_plugin_venv() (re-exec the process under the plugin's provisioned interpreter before any shared-lib import). Stdlib-only by design; a drift test asserts the copies in sibling plugins match this source. Open it when a script in this directory exits with code 3 or when a sibling plugin's guard copy looks out of date.

Template generators

plugins/skills-kit/scripts/gen_standards_doc.py -- regenerates the delimited generated region of the standards reference doc from rule_catalog.py, audit.py thresholds, and the shipped standards layer. Run in place to rewrite, or with --check for a CI drift gate.

plugins/skills-kit/scripts/gen_workflow_js.py -- canonical template for the four md-domain remediate lane workflow scripts. Renders the shared lane-route chunk, per-lane fragments, and the codex bridge helper; a drift test asserts the shipped .js files are byte-identical to the rendered output. Edit here, then regenerate.

Lane resolution and dispatch

plugins/skills-kit/scripts/resolve_standards.py -- CLI that resolves the layered standards config to a single JSON object (disabled rules, threshold overrides, authored standards paths, audit mode, lane models). Called once per md-domain lane family; the workflow script threads the result into each detect and classify call.

plugins/skills-kit/scripts/run_lane.py -- executor for one codex lane entry. Reads the lane payload and input digest from stdin, calls skills_kit_lib.lane_bridge, and prints one JSON status line. The md-lane-bridge agent invokes this once per codex dispatch.

plugins/skills-kit/scripts/skills_kit_tool.py -- general-purpose dispatcher for skills_kit_lib subcommands (audit, classify, tag, material, lane-models). Puts the plugin root on sys.path and runs the named module as __main__, so relative paths in the arguments resolve against the caller's working directory.

Version probe

plugins/skills-kit/scripts/print_version.py -- prints the plugin name@version from the manifest and emits a soft bootstrap-provisioning warning on stderr. Stdlib-only and never exits nonzero; safe to call from any hook or launcher shim.
