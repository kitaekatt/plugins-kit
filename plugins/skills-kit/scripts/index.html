The skills-kit plugin's scripts for bootstrap guarding, code generation, standards resolution, and command dispatch

These are the skills-kit plugin standalone entry points. They wrap the skills_kit_lib package, where audit, classify, tag, and resolution logic lives. Their shared constraint is the virtualenv boundary: a subset runs before bootstrap provisions the venv, so it is stdlib-only and refuses shared-library imports until the guard re-execs the process inside that venv. The rest assume the venv exists and either resolve layered configuration or dispatch a library command. Two scripts close a loop by regenerating marked regions from one source of truth and exposing a check mode for drift tests.

Where to start

Start with plugins/skills-kit/scripts/bootstrap_guard.py, the canonical guard every script re-execs through. It is the source other plugins copy byte-for-byte and states the directory rule: a script stays stdlib-only so it can run before the venv exists.

Entry points

  • plugins/skills-kit/scripts/bootstrap_guard.py Stdlib-only guard that detects whether bootstrap provisioned the plugin, prints the absence message, and re-execs under the plugin venv. Other plugins keep byte-identical copies.
  • plugins/skills-kit/scripts/print_version.py Prints the plugin name and version from its manifest; warns on stderr without exiting when bootstrap has not provisioned it. A launcher banner.
  • plugins/skills-kit/scripts/gen_standards_doc.py Rewrites the marked region of the standards reference doc from the rule catalog and threshold defaults. With --check it exits 1 on drift and writes nothing.
  • plugins/skills-kit/scripts/gen_workflow_js.py Renders four lane scripts from one template plus per-lane fragments and rewrites a shared lane-route chunk inside hand-written detect scripts. With --check it asserts shipped files are byte-identical.
  • plugins/skills-kit/scripts/resolve_standards.py Resolves layered standards config to one JSON object: disabled rules, threshold overrides, per-primitive standards paths, fix mode, and lane models. md-domain audit lanes read it once per run.
  • plugins/skills-kit/scripts/skills_kit_tool.py Dispatcher for audit, classify, tag, material, and lane-models. It re-execs under the plugin venv, then runs the matching skills_kit_lib module as the main program.

Generated-region check

  • Edit the source of truth a generator reads, then run plugins/skills-kit/scripts/gen_standards_doc.py or plugins/skills-kit/scripts/gen_workflow_js.py with no flags to rewrite the shipped file in place.
  • Run the same generator with --check; it exits 1 on drift and writes nothing, the assertion a CI test makes.
