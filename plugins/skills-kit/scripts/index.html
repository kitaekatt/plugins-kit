The skills-kit plugin's scripts for bootstrap guarding, code generation, standards resolution, and command dispatch

Six Python files sit here, each a standalone entry point or a shared dependency for the skills-kit plugin's audit and remediation pipeline. They resolve layered standards configuration, dispatch audit and classification commands, generate the workflow scripts the md-domain lanes execute, and regenerate reference documentation from single sources of truth. A stdlib-only guard module sits at the bottom of the dependency chain: every other script imports it before touching the shared library, and it re-execs the process under the plugin's provisioned venv when the launcher did not already do so.

Where to start

Open plugins/skills-kit/scripts/skills_kit_tool.py to see how a hook or user invokes the audit, classify, tag, material, and lane-models subcommands. If you are tracing how a project's standards layer becomes the JSON the lanes consume, plugins/skills-kit/scripts/resolve_standards.py is the shorter path in.

Routes

  • Dispatch an audit command
    1. plugins/skills-kit/scripts/skills_kit_tool.py audit <args>
    2. re-execs under the plugin venv via the guard
    3. runs the matching skills_kit_lib module as __main__
  • Resolve standards to JSON
    1. plugins/skills-kit/scripts/resolve_standards.py --project-root <dir>
    2. calls standards_resolve.resolve() over the shipped and user-authored layers
    3. JSON on stdout: disabled rules, thresholds, standards paths, fix mode, lane models
  • Regenerate workflow scripts
    1. plugins/skills-kit/scripts/gen_workflow_js.py
    2. renders the canonical template with per-lane fragments and the lane-route chunk
    3. writes the four md-domain remediate .js files into the workflow directory
  • Regenerate the standards reference
    1. plugins/skills-kit/scripts/gen_standards_doc.py
    2. reads rule_catalog.RULES, audit.py THRESHOLDS, and the shipped standards layer
    3. splices the delimited generated section into the standards reference doc

Bootstrap guard

plugins/skills-kit/scripts/bootstrap_guard.py is the stdlib-only venv detection and re-exec module. It checks for a per-plugin bootstrap log, locates the provisioned venv interpreter, and re-execs the current process into it when the caller's interpreter lacks the shared-library .pth. A loop guard environment flag names the target interpreter so a child of another plugin's re-exec never inherits a stale bit. Imported by every other script here before the shared library loads.

Command entry points

plugins/skills-kit/scripts/skills_kit_tool.py dispatches audit, classify, tag, material, and lane-models to the matching skills_kit_lib module via runpy. It is the entry point that hooks and other plugins call; relative paths in the arguments resolve against the caller's working directory.

plugins/skills-kit/scripts/resolve_standards.py resolves the layered standards configuration (shipped defaults plus user-authored files) to a single JSON object the audit lanes consume. It re-execs under the venv before importing lane_models, which requires bootstrap_lib.

plugins/skills-kit/scripts/print_version.py prints the plugin name@version from the manifest and performs a soft bootstrap check on stderr. It never blocks the banner line; the check is informational.

Generators

plugins/skills-kit/scripts/gen_workflow_js.py is the canonical template and per-lane fragment data for the four md-domain remediate workflow scripts. A drift test in CI asserts the shipped .js files are byte-identical to the rendered output. The shared lane-route chunk is also spliced into the hand-written detect, classify, and generate scripts.

plugins/skills-kit/scripts/gen_standards_doc.py regenerates the delimited generated section of the standards reference doc from rule_catalog and audit thresholds. A --check mode exits 1 on drift without writing; CI runs that mode.
