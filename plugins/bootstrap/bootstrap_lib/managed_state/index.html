Harness-independent declarative state management and safe symlink convergence for bootstrap projects.

This package is the harness-independent state half of bootstrap. A project declares desired working-tree items; each item is left, created, or repaired. The plan is re-checked before mutation so concurrent convergence is not clobbered.

Where to start

plugins/bootstrap/bootstrap_lib/managed_state/model.py defines Operation, State, Status, Resource, and ResourceApplyError. plugins/bootstrap/bootstrap_lib/managed_state/runner.py turns inspect results into plan and run outcomes. plugins/bootstrap/bootstrap_lib/managed_state/__init__.py exposes the public surface.

Routes

  • Follow one operation
    1. plugins/bootstrap/bootstrap_lib/managed_state/model.py declare resources.
    2. plugins/bootstrap/bootstrap_lib/managed_state/runner.py plan() marks will_change or blocked; run() executes changes and converts failures to report data.
    3. plugins/bootstrap/bootstrap_lib/managed_state/cli.py run_cli() prints JSON or a one-line report and exits 0 or 1.
  • Add a resource
    1. plugins/bootstrap/bootstrap_lib/managed_state/model.py implement Resource inspect() and converge().
    2. plugins/bootstrap/bootstrap_lib/managed_state/symlink.py use the built-in symlink resource, including backup and rollback, as reference.
  • bootstrap_lib Bootstrap plugin shared library: the engine pass, platform tool installers, Codex CLI integration, environment and config management, code review pipeline, and remediation queue.
