Bootstrap plugin shared library: the engine pass, platform tool installers, Codex CLI integration, environment and config management, code review pipeline, and remediation queue.

bootstrap_lib is the Python library behind the bootstrap plugin. A SessionStart pass reads layered manifests and runs unprivileged checks, idempotent fixes, and authoritative re-checks; deferred work goes to a remediation queue. Backends are stdlib-only, and frozen modules serve as cross-plugin contracts. A code-review subsystem keeps its own subdirectory, and the declarative state-management work sits beside it with its own orientation page.

Where to start

Open plugins/bootstrap/bootstrap_lib/engine.py first: it is the SessionStart pass. For settings layering, open plugins/bootstrap/bootstrap_lib/config_resolve.py.

Routes

  • Remediation
    1. plugins/bootstrap/bootstrap_lib/engine.py defers incomplete work to plugins/bootstrap/bootstrap_lib/fix_queue.py; plugins/bootstrap/bootstrap_lib/fix_runner.py runs it later.
  • Tool install
    1. plugins/bootstrap/bootstrap_lib/engine.py routes to plugins/bootstrap/bootstrap_lib/brew.py on macOS, plugins/bootstrap/bootstrap_lib/apt.py on Ubuntu, plugins/bootstrap/bootstrap_lib/scoop.py on Windows, or plugins/bootstrap/bootstrap_lib/downloader.py for url and sha256.
