Bootstrap engine and shared library for platform tool installation, Codex CLI integration, environment and config management, code review, and remediation.

Shared Python library for the bootstrap plugin. The engine module orchestrates the session-start pass, with backends installing tools via apt, brew, or download. A Codex layer probes the CLI and installs its hook, while config and env modules persist variables and resolve layered manifests. A fix queue defers work needing a human terminal; subpackages cover code review and managed state. Remaining modules implement check-and-fix contracts, stamps, and platform shims.

Where to start

Open plugins/bootstrap/bootstrap_lib/engine.py for pass orchestration, locking, and crash containment. Every other module is called from it.

Routes

  • Run a bootstrap pass
    1. plugins/bootstrap/bootstrap_lib/engine.py reads manifests, dispatches phases
    2. plugins/bootstrap/bootstrap_lib/apt.py / plugins/bootstrap/bootstrap_lib/brew.py / plugins/bootstrap/bootstrap_lib/downloader.py install tools
    3. plugins/bootstrap/bootstrap_lib/fix_queue.py harvests deferred failures
  • Wire up Codex
    1. plugins/bootstrap/bootstrap_lib/codex_detection.py probes for a usable CLI
    2. plugins/bootstrap/bootstrap_lib/codex_hook.py installs the session hook
    3. plugins/bootstrap/bootstrap_lib/agent_skills_check.py links project skills into the Codex directory
  • Resolve and persist config
    1. plugins/bootstrap/bootstrap_lib/config_resolve.py merges shipped, user, and project YAML
    2. plugins/bootstrap/bootstrap_lib/config_check.py validates and seeds per-plugin config
    3. plugins/bootstrap/bootstrap_lib/env_var_check.py writes exports to rc files

Core modules

  • plugins/bootstrap/bootstrap_lib/engine.py - single-instance lock, version-aware retry, crash containment
  • plugins/bootstrap/bootstrap_lib/atomic_write.py - mkstemp + os.replace helper shared by all writers
  • plugins/bootstrap/bootstrap_lib/apt.py - apt-get with passwordless-sudo detection
  • plugins/bootstrap/bootstrap_lib/brew.py - macOS formulae and casks
  • plugins/bootstrap/bootstrap_lib/downloader.py - binary download with sha256 verification and atomic staging

Config and environment

  • plugins/bootstrap/bootstrap_lib/config.py - config load and schema migration (v0-v6)
  • plugins/bootstrap/bootstrap_lib/config_resolve.py - layered YAML resolution
  • plugins/bootstrap/bootstrap_lib/env_features.py - symlink, shell-rc, and login-item check/fix primitives
  • plugins/bootstrap/bootstrap_lib/env_manifest.py - env.json four-layer load and env gate stamp
  • plugins/bootstrap/bootstrap_lib/env_var_check.py - env-var persistence to rc files
  • plugins/bootstrap/bootstrap_lib/display_relay.py - age-stamped relay for pending display message

Remediation and guards

  • plugins/bootstrap/bootstrap_lib/fix_queue.py - deferred ops, quick work first, interactive runner
  • plugins/bootstrap/bootstrap_lib/bootstrap_guard.py - provisioned-venv detection and re-exec
  • plugins/bootstrap/bootstrap_lib/claudx.py - plugin-dir propagation for nested claude children

Aliases and subpackages

  • plugins/bootstrap/bootstrap_lib/_contracts_alias.py - substitutes katsoft-contracts modules
  • plugins/bootstrap/bootstrap_lib/_llm_kit_alias.py - substitutes katsoft-llm-kit modules
  • plugins/bootstrap/bootstrap_lib/execution_event.py - alias of katsoft_contracts.execution_event
  • plugins/bootstrap/bootstrap_lib/codex.py - alias of llm_kit.adapters.codex_command
  • plugins/bootstrap/bootstrap_lib/code_review - review pipeline with defaults, mechanical, and repository subpackages
  • plugins/bootstrap/bootstrap_lib/managed_state - persistent state files across passes
