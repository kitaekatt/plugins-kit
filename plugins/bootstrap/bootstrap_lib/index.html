Bootstrap engine and shared library for platform tool installation, Codex CLI integration, environment and config management, code review, and remediation.

This package is the Python side of the bootstrap plugin. It runs a background engine pass, keeps platform tools and interpreter environments in shape, and exposes shared contracts that other plugins import. Two internal packages hold larger subsystems, so the top-level files mostly do checks, fixes, and orchestration.

Where to start

plugins/bootstrap/bootstrap_lib/engine.py Open it first for pass phases, lock behavior, crash containment, and the hook response shape.

Routes

  • Run an engine pass
    1. plugins/bootstrap/bootstrap_lib/engine.py
    2. plugins/bootstrap/bootstrap_lib/proc_lock.py
    3. plugins/bootstrap/bootstrap_lib/session_env.py
  • Resolve layered config
    1. plugins/bootstrap/bootstrap_lib/config_resolve.py
    2. plugins/bootstrap/bootstrap_lib/manifest_merge.py
    3. plugins/bootstrap/bootstrap_lib/config_check.py

Engine pass

  • plugins/bootstrap/bootstrap_lib/engine.py Main entry; use it for pass order, lock contention, and crash reporting.
  • plugins/bootstrap/bootstrap_lib/proc_lock.py Single-instance lock for overlapping session starts.
  • plugins/bootstrap/bootstrap_lib/session_env.py Buffers session exports and writes the environment block once.
  • plugins/bootstrap/bootstrap_lib/stamps.py Reads and writes version and cooldown stamps.
  • plugins/bootstrap/bootstrap_lib/log.py Appends structured bootstrap log entries.
  • plugins/bootstrap/bootstrap_lib/messages.py Shapes user-visible pass messages.

Platform tools

  • plugins/bootstrap/bootstrap_lib/apt.py installs Ubuntu packages non-interactively; plugins/bootstrap/bootstrap_lib/brew.py detects and installs Homebrew formulae and casks; plugins/bootstrap/bootstrap_lib/scoop.py installs Scoop packages; plugins/bootstrap/bootstrap_lib/downloader.py downloads and verifies archives.
  • plugins/bootstrap/bootstrap_lib/tool_check.py reports whether a tool is usable; plugins/bootstrap/bootstrap_lib/tool_paths.py tracks bootstrap-managed tool paths. Package-index and interpreter checks live beside these backends.

Codex integration

  • plugins/bootstrap/bootstrap_lib/codex.py Detects the Codex CLI and builds its exec argv.
  • plugins/bootstrap/bootstrap_lib/codex_hook.py Installs and strips bootstrap's user-level Codex hook.
  • plugins/bootstrap/bootstrap_lib/claudx.py Propagates claudx test sessions into nested claude children.

Environment and config

  • plugins/bootstrap/bootstrap_lib/config.py loads, migrates, and saves bootstrap config; plugins/bootstrap/bootstrap_lib/config_check.py validates plugin config and runs autodetect; plugins/bootstrap/bootstrap_lib/config_resolve.py deep-merges shipped, user, and project config layers.
  • plugins/bootstrap/bootstrap_lib/env_manifest.py reads env manifest layers and machine identity; plugins/bootstrap/bootstrap_lib/env_features.py applies symlink, shell rc, and macOS default features; plugins/bootstrap/bootstrap_lib/env_var_check.py persists and live-exports variables.
  • plugins/bootstrap/bootstrap_lib/path_check.py manages PATH entries; plugins/bootstrap/bootstrap_lib/path_prune.py removes stale entries; plugins/bootstrap/bootstrap_lib/path_repair.py repairs broken paths.

Code review

  • plugins/bootstrap/bootstrap_lib/code_review/pipeline.py Drives review lanes; open it to see how profiles, prompts, and output are combined.
  • plugins/bootstrap/bootstrap_lib/code_review/defaults/review_profiles.yaml and plugins/bootstrap/bootstrap_lib/code_review/defaults/mechanical_checks.yaml provide default profiles and checks.
  • plugins/bootstrap/bootstrap_lib/code_review/mechanical/__init__.py exposes file-level mechanical checks; plugins/bootstrap/bootstrap_lib/code_review/mechanical_repository/__init__.py exposes repository-level checks.
  • plugins/bootstrap/bootstrap_lib/code_review/ledger.py tracks review state; plugins/bootstrap/bootstrap_lib/code_review/triviality.py filters trivial changes.

Managed state

  • plugins/bootstrap/bootstrap_lib/managed_state/cli.py exposes the CLI; plugins/bootstrap/bootstrap_lib/managed_state/model.py defines state; plugins/bootstrap/bootstrap_lib/managed_state/runner.py executes updates; plugins/bootstrap/bootstrap_lib/managed_state/symlink.py handles symlinked state.

Marketplace and shared libraries

  • plugins/bootstrap/bootstrap_lib/marketplace_lifecycle.py installs, updates, and removes marketplace plugins.
  • plugins/bootstrap/bootstrap_lib/shared_lib.py links shared libraries into plugin venvs.
  • plugins/bootstrap/bootstrap_lib/plugin_resolve.py resolves plugin locations; plugins/bootstrap/bootstrap_lib/plugin_tiers.py orders plugin tiers.
  • plugins/bootstrap/bootstrap_lib/registry_repair.py repairs plugin registry state; plugins/bootstrap/bootstrap_lib/skill_material.py materializes skill content.

Remediation and events

  • plugins/bootstrap/bootstrap_lib/fix_queue.py queues elevation and deferred fixes; plugins/bootstrap/bootstrap_lib/fix_runner.py runs them.
  • plugins/bootstrap/bootstrap_lib/execution_event.py validates shared execution-event envelopes.
  • plugins/bootstrap/bootstrap_lib/interrupt_contract.py handles interrupt contracts.
