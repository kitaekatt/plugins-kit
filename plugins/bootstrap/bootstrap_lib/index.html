Bootstrap engine and shared library for platform tool installation, Codex CLI integration, environment and config management, code review, and remediation.

This is the shared Python library behind the bootstrap plugin. It runs as a background SessionStart pass: installing platform tools, resolving layered configuration, managing environment features, probing for Codex, and deferring operations that need a terminal. The library is organized by concern with a single entry-point module that drives the whole pass. Most modules are stdlib-only and side-effect-free in their check half; the fix half does the filesystem and VCS work. Roughly eighty additional support modules complete the library.

Where to start

Open plugins/bootstrap/bootstrap_lib/engine.py for the full pass: it acquires the single-instance lock, runs each phase in order, and emits the hook JSON response. Every other module here is a primitive it calls.

Routes

  • Trace a tool install
    1. The engine dispatches by platform: plugins/bootstrap/bootstrap_lib/apt.py on Ubuntu, plugins/bootstrap/bootstrap_lib/brew.py on macOS, or plugins/bootstrap/bootstrap_lib/downloader.py for a URL-sha pair.
  • Debug the Codex hook
    1. plugins/bootstrap/bootstrap_lib/codex_hook.py writes the guarded SessionStart entry into the user's hooks file.
    2. plugins/bootstrap/bootstrap_lib/codex_detection.py answers whether the CLI is available; stdlib-only, cached for the process.
  • Follow a deferred fix
    1. plugins/bootstrap/bootstrap_lib/fix_queue.py harvests elevation descriptors from pass failures, orders them quick-first, and writes the queue file.
    2. The engine's elevation step then launches the runner and waits with a bounded timeout.

Engine and entry point

  • plugins/bootstrap/bootstrap_lib/engine.py -- the full pass: lock, phase dispatch, crash containment, hook response.
  • plugins/bootstrap/bootstrap_lib/__init__.py -- one-line package docstring.

Package-manager backends

  • plugins/bootstrap/bootstrap_lib/apt.py -- Ubuntu apt-get install with privilege probes; defers when sudo is unavailable.
  • plugins/bootstrap/bootstrap_lib/brew.py -- macOS Homebrew formula and cask install; detect-only for the brew binary itself.
  • plugins/bootstrap/bootstrap_lib/downloader.py -- fetch, sha256-verify, and install a binary or font archive into the user's bin directory.

Codex integration

  • plugins/bootstrap/bootstrap_lib/codex_detection.py -- stdlib-only CLI probe; answers whether Codex is usable before any venv exists.
  • plugins/bootstrap/bootstrap_lib/codex_hook.py -- installs and strips the guarded SessionStart hook in the user's hooks file.
  • plugins/bootstrap/bootstrap_lib/codex.py -- one-line alias of the llm-kit Codex command builder.
  • plugins/bootstrap/bootstrap_lib/_llm_kit_alias.py -- the alias machinery that replaces sys.modules entries with the canonical llm-kit module.

Config and environment

  • plugins/bootstrap/bootstrap_lib/config.py -- bootstrap's own config: load, migrate across six schema versions, save.
  • plugins/bootstrap/bootstrap_lib/config_check.py -- per-plugin config init, field validation, and autodetect lifecycle.
  • plugins/bootstrap/bootstrap_lib/config_resolve.py -- layered deep-merge of shipped defaults, user config, and project override.
  • plugins/bootstrap/bootstrap_lib/env_manifest.py -- the env.json identity-bearing manifest: four-layer load, machine-registry gate, env-state stamp.
  • plugins/bootstrap/bootstrap_lib/env_features.py -- check/fix primitives for the env phase: symlinks, shell rc, macOS defaults, hotkeys, login items.
  • plugins/bootstrap/bootstrap_lib/env_var_check.py -- environment-variable persistence (rc or Windows registry) and live session export.

Agent skills and session

  • plugins/bootstrap/bootstrap_lib/agent_skills_check.py -- links the agents skills directory to the Claude skills directory when Codex is present and the project is a git root.
  • plugins/bootstrap/bootstrap_lib/claudx.py -- propagates the claudx test session's plugin flags to nested claude children.
  • plugins/bootstrap/bootstrap_lib/display_relay.py -- stamps the pending bootstrap display message with its age at delivery.

Remediation

  • plugins/bootstrap/bootstrap_lib/fix_queue.py -- harvests deferred operations, orders them quick-first, writes the queue file and launcher script, launches the runner.

Shared primitives and aliases

  • plugins/bootstrap/bootstrap_lib/atomic_write.py -- the single mkstemp + os.replace implementation shared across the library.
  • plugins/bootstrap/bootstrap_lib/bootstrap_guard.py -- vendored stdlib-only guard; exits with an actionable message when bootstrap has not provisioned a plugin.
  • plugins/bootstrap/bootstrap_lib/_contracts_alias.py -- alias machinery for the katsoft-contracts distribution.
  • plugins/bootstrap/bootstrap_lib/execution_event.py -- one-line alias of the katsoft-contracts execution-event module.

Code review and managed state

The code_review subdirectory holds mechanical code-review check definitions organized into three sub-groups. The managed_state subdirectory holds persistent state tracking for the engine pass.
