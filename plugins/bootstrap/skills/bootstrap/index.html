Reference for the bootstrap engine: session-start behavior, the bootstrap.json manifest schema, the CLI, and patterns for managing plugin dependencies. The skill file carries the contract data and indexes twelve references that each cover one aspect in depth. The references cross-link by topic, so landing on one surfaces the neighbors. Open the skill file first; it states which topic each reference owns.

Where to start

Open plugins/bootstrap/skills/bootstrap/SKILL.md for the message-outcomes table and the references index. It is the single entry that points to every other document here and states the load-bearing contract in-line.
