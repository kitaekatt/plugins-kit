Reference for the bootstrap engine's behavior, the bootstrap.json manifest, the bootstrap CLI, and the patterns for managing plugin dependencies and their lifecycle

This skill sits beside the bootstrap plugin code and is a reference manual for how the bootstrap engine provisions a user machine: what a session-start bootstrap does, how a machine converges after an update, and how to declare the dependencies it installs. It is one entry file plus a references directory of 13 deeper documents. The entry file carries the load-bearing facts, each with a keyword list and a one-line pointer to the document that holds the full mechanics, and each reference states its audience and the failure modes it rules out. You read it when a SessionStart bootstrap message arrives, when a bootstrap.json needs configuring, or when a machine is mid-convergence and someone asks what to do.

Where to start

Open plugins/bootstrap/skills/bootstrap/SKILL.md: its contract facts carry keywords and one-line pointers to each of the 13 deeper documents, so it answers most interpretation questions on the spot. For manifest authoring go straight to plugins/bootstrap/skills/bootstrap/references/manifest-reference.md; for a live machine's state, the operational references carry it.

Routes

  • Interpret a bootstrap message
    1. plugins/bootstrap/skills/bootstrap/SKILL.md -- the four session-start outcomes: silent pass, silent install, silent skip, fix-all prompt; no output means healthy, not broken.
    2. plugins/bootstrap/skills/bootstrap/references/remediation-reference.md -- the UX ladder, the two outcomes, and the per-condition tables when a fix-all arrived.
  • A published update lands mid-session
    1. plugins/bootstrap/skills/bootstrap/SKILL.md -- the single-session convergence fact: provisioning is done once engine_ran_version equals the installed version; a restart loads new plugin code only.
    2. plugins/bootstrap/skills/bootstrap/references/plugin-reload-lifecycle.md -- the measured reload versus restart layers, the harvest, and the fresh-machine rescue.
  • Force a pass from the terminal
    1. plugins/bootstrap/skills/bootstrap/SKILL.md -- the bootstrap run force path and its difference from a hook pass.
    2. plugins/bootstrap/skills/bootstrap/references/bootstrap-cli.md -- every verb, exit code, lock refusal, and the profile and python subcommands.
  • Declare an optional precondition
    1. plugins/bootstrap/skills/bootstrap/references/deferred-requirements.md -- the principle: detect early, ask at the point of need, and the add_deferred_requirement handoff.
    2. plugins/bootstrap/skills/bootstrap/references/action-triggered-install.md -- the plugin-specific instance: install: "manual", preflight, install on consent, no restart.
