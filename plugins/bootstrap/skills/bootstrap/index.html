Reference for the bootstrap engine's behavior, the bootstrap.json manifest, the bootstrap CLI, and the patterns for managing plugin dependencies and their lifecycle

This is the reference documentation for the bootstrap plugin. The top-level skill file is the contract surface: it names the four session-start message outcomes, the single-session update convergence protocol, the terminal CLI lever, and the cooldown reset request protocol. Everything deeper is one level down, grouped by the job you are doing: understanding engine mechanics, writing a manifest, running a pass from the terminal, or wiring a dependency pattern into a new plugin. Cross-links between the reference files are load-bearing; a file that points to another is routing you to the authoritative schema, not restating it.

Where to start

Open plugins/bootstrap/skills/bootstrap/SKILL.md first for the message-outcome table and the update-lifecycle fact; those two facts answer most "why did I see this" questions without needing a reference. If your question is about writing or editing a manifest, go straight to the plugins/bootstrap/skills/bootstrap/references/manifest-reference.md instead.

The contract surface

plugins/bootstrap/skills/bootstrap/SKILL.md carries the four facts a session needs: the message-outcome table, the update convergence protocol, the CLI lever, and the cooldown reset request protocol. Each fact carries its gotchas inline; the detail it defers to a reference is linked at the bottom of the fact block.

Engine and lifecycle

  • plugins/bootstrap/skills/bootstrap/references/engine-internals.md -- two-phase architecture, phase sequence, registry self-repair, single-instance lock; open when a pass behaved differently than expected.
  • plugins/bootstrap/skills/bootstrap/references/plugin-reload-lifecycle.md -- when code, registration, and firing each go live; the harvest, rescue, and mid-session install relaunch; open after an update that did not converge.

Manifest and configuration

  • plugins/bootstrap/skills/bootstrap/references/manifest-reference.md -- the full bootstrap.json field reference with merge semantics; open before adding or editing any manifest entry.
  • plugins/bootstrap/skills/bootstrap/references/plugin-setup-pattern.md -- declaring and validating user-specific config via the config section; open when a plugin needs API keys or preferences.
  • plugins/bootstrap/skills/bootstrap/references/python-interpreter.md -- the BOOTSTRAP_PYTHON and BOOTSTRAP_PROJECT_PYTHON call-site forms and their coverage table; open when a script needs an interpreter.

Terminal CLI

  • plugins/bootstrap/skills/bootstrap/references/bootstrap-cli.md -- every bootstrap subcommand, exit codes, profile management, and the project-only mode; open before forcing a pass from the terminal.

Remediation
