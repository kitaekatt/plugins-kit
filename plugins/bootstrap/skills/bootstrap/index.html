Reference for the bootstrap engine's behavior, the bootstrap.json manifest, the bootstrap CLI, and the patterns for managing plugin dependencies and their lifecycle

This skill is the working reference for the bootstrap engine, the SessionStart machinery that installs and provisions Claude Code plugins on a machine. One file holds the load-bearing contract - message outcomes, the update lifecycle, the bootstrap command, and the remediable condition categories - and the deeper material sits one level below it, organized by topic: how the engine behaves, the manifest schema, and how plugin dependencies are declared, managed, and remediated. Each fact in the contract names the document that carries its mechanics, so the contract reads as a table of contents for its own depth. Open it when a session-start message or a fix-all prompt needs interpreting, and follow the pointer when you need the mechanics behind a fact.

Where to start

Start with plugins/bootstrap/skills/bootstrap/SKILL.md. Its contract - message outcomes, the update lifecycle, the bootstrap command, and the condition categories - is the surface almost every question lands on, and each fact names the document that holds the mechanics.
