Reference for the bootstrap engine's behavior, the bootstrap.json manifest, the bootstrap CLI, and the patterns for managing plugin dependencies and their lifecycle

Reference material for a running bootstrap installation. It covers session-start behavior, the manifest schema, the terminal command, and dependency and lifecycle patterns. Start with the skill file, then follow its keyword-indexed facts to the reference beside it. A healthy bootstrap prints nothing, so this index also explains what a quiet session start did.

Where to start

plugins/bootstrap/skills/bootstrap/SKILL.md carries the load-bearing facts. Open the matching reference from the topic list rather than reading all files in order.
