Commit and publish gates, isolated dev testing, code-review skill rendering, and reviewer-model benchmarking for the plugins-kit marketplace

This is the operational tooling for the plugins-kit marketplace: commit-time invariant checks, the release pipeline, isolated dev testing, code-review skill rendering, and reviewer-model benchmarking. Every commit gate judges the git index rather than the shared working tree, because concurrent agent sessions make a worktree-wide check both too strict and too loose. The pre-commit hooks are escapable advice delivered while you still have context; the publish script is the unbypassable gate that re-runs the same invariants from the same source before anything reaches master. A corpus of twenty-four paired test cases supports reviewer-model benchmarking.

Where to start

Open scripts/pre-commit-version-check.sh to see the full check chain and the layering rationale. Open scripts/publish.py when you are about to ship.

Routes

  • Commit a plugin change
    1. scripts/pre-commit-version-check.sh chains five staged checks on every commit
    2. scripts/regen_marketplace.py --check --staged, scripts/check-staged-version-bump.sh, scripts/check_pyproject_sync.py, scripts/check_bootstrap_dependency.py, and scripts/check_agent_directives.py each judge the index and skip when the commit stages none of their inputs
  • Publish the marketplace
    1. scripts/publish.py runs preflight: clean tree, on dev, range has publishable content
    2. regenerates the marketplace manifest, pushes dev, fast-forwards master, verifies the published artifacts
  • Test a plugin in isolation
    1. scripts/claude_plugin_test.py launches a session with a synthetic registry and redirected data root; no machine-global writes
    2. scripts/dev-tree.py dev rewrites the machine-global registry to point at the working copy; use when the engine must read dev manifests

Commit gates

  • scripts/pre-commit-version-check.sh -- the orchestrator; chains five staged checks and the leak guard on every commit
  • scripts/_gitindex.py -- shared index-aware and scoped Git helpers; every gate imports it
  • scripts/check-staged-version-bump.sh -- blocks a commit that changes a plugin without a version bump since the last publish point
  • scripts/check_pyproject_sync.py -- blocks a project-manifest version that disagrees with the plugin manifest
  • scripts/check_bootstrap_dependency.py -- blocks a plugin that does not declare the bootstrap dependency
  • scripts/check_agent_directives.py -- blocks banned agent-directive phrasing under the shipped plugin tree
  • scripts/precommit_guard.py -- blocks project-derived or machine-emitted data from staged commits
  • scripts/regen_marketplace.py -- regenerates the marketplace manifest from plugin manifests; also the --check gate

Publish pipeline

  • scripts/publish.py -- the four-step release flow: preflight, regenerate, push dev, fast-forward master, verify
  • scripts/_packages.py -- consumer target validation and private-index Git helpers for publish
  • scripts/import_package_targets.py -- imports verified library releases into the offline target artifact

Isolated dev testing

  • scripts/claude_plugin_test.py -- launches an isolated Claude session with a synthetic registry and redirected data root
  • scripts/dev-tree.py -- rewrites the machine-global registry to point at the working copy; idempotent with backup
  • scripts/claudx_plugin_dirs.py -- prints the plugin directories a claudx session should load, filtered by enablement

Skill generation

  • scripts/gen_code_review_skills.py -- renders both git-kit and p4-kit code-review skills from one template; --check enforces byte-identity

Diagnostics and benchmarking

  • scripts/cache_status.py -- diffs plugin cache content against the local source tree; --detailed for file-level output
  • scripts/plugin-versions.sh -- compares version strings across local, marketplace clone, installed registry, and cache
  • scripts/check_model_dispatch.py -- validates orchestration model identifiers by real CLI dispatch; run on demand, not in any gate
  • scripts/relaunch_e2e.py -- macOS end-to-end test for relaunch-kit under a pty
  • scripts/review-bakeoff/corpus -- twenty-four paired test cases covering Python, shell, YAML, JSON, Markdown, and CSV defects
