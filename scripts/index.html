Commit and publish gates, isolated dev testing, code-review skill rendering, and reviewer-model benchmarking for the plugins-kit marketplace

This directory keeps the plugins marketplace honest: commit gates, publish, working-copy testing, and reviewer bakeoff. Commit checks judge the staged index, not the shared working tree; publish re-runs the same invariants unescapeably. The sections below organize those scripts by the flows they support.

Where to start

Open scripts/pre-commit-version-check.sh: names every commit check in order and carries the install line. scripts/publish.py: release flow source of truth.

Routes

  • Commit and ship a plugin change
    1. Bump the version in the plugin metadata and stage it.
    2. scripts/regen_marketplace.py and stage the rewritten marketplace manifest.
    3. scripts/publish.py: preflight, push dev, fast-forward master, verify.
  • What one commit runs
    1. scripts/pre-commit-version-check.sh chains the five consumer-correctness checks; scripts/precommit_guard.py runs separately and is unforgiving.
  • Test a plugin from the working copy
    1. scripts/claude_plugin_test.py writes a synthetic registry only the dev engine can see.
    2. scripts/dev-tree.py dev; normal restores from the sidecar backup.
    3. scripts/claudx_plugin_dirs.py prints the enabled plugin directories.
  • Bakeoff one reviewer model
    1. scripts/review-bakeoff/run_bakeoff.py uses endpoint arms; harness: claude aliases use prompts and ingest.
    2. score prints recall, precision, decoy false-positive rate, and positive noise per arm.

Publishing

  • scripts/publish.py - four-step release: preflight, push dev, fast-forward master, verify. Preflight re-runs skippable checks unescapeably; --only ships one plugin.
  • scripts/regen_marketplace.py - rebuilds marketplace manifest from plugin version files; --check --staged is the drift guard; --only commits one bump.

Commit-time gates

  • scripts/pre-commit-version-check.sh - chains the five consumer-correctness checks; escapeable here, not at publish.
  • scripts/precommit_guard.py - separate leak guard; blocks project-derived and machine-emitted data from staged commits.
  • scripts/_gitindex.py - one implementation of index-aware checking: bounded git calls, NUL-separated paths, skip, index, or worktree verdict.
  • scripts/check-staged-version-bump.sh - blocks an unchanged plugin version since the last publish point, with a weaker fallback.
  • scripts/check_pyproject_sync.py - checks that the version agrees with the authoritative plugin version.
  • scripts/check_bootstrap_dependency.py - blocks plugins that omit the bootstrap dependency, except bootstrap itself.
  • scripts/check_agent_directives.py - greps shipped plugin text for banned agent-directive phrasing; same-line marker exempts quoted phrases.

Dev testing and cache visibility

  • scripts/dev-tree.py - points the machine registry at the working copy (dev) or restores it (normal); lossless backup.
  • scripts/claude_plugin_test.py - tests working copy without the machine registry; --fresh is the honest periodic check.
  • scripts/claudx_plugin_dirs.py - prints enabled plugin directories for a plain plugin-dir launch; reads only.
  • scripts/cache_status.py - diffs local source against the plugin cache; a differs verdict on a dev branch is expected.
  • scripts/plugin-versions.sh - reports versions across repo, marketplace clone, registry, and cache.

Code review skill rendering

  • scripts/gen_code_review_skills.py - renders both code review skills and effort agents; --check fails on drift; commit template and rendered files together.

Model dispatch check

  • scripts/check_model_dispatch.py - validates orchestrate policy model identifiers by real dispatch; a tool, not an automatic gate.

Reviewer bakeoff

  • scripts/review-bakeoff/SPEC.md - on-disk contract: case format, matching rule, four metrics; decoy false-positive rate is headline.
  • scripts/review-bakeoff/README.md - subcommands with exact invocations.
  • scripts/review-bakeoff/run_bakeoff.py - runs and scores: run for endpoint arms, prompts and ingest for harness: claude aliases, score for per-arm summary.
  • scripts/review-bakeoff/corpus - 24 cases, one directory each: a case file states the planted bug or decoy rule, and the diff bytes a lane sees; add cases here.
  • README.md Marketplace entry point.
  • repo-scripts Tests that assert these scripts.
  • docs Long-form reference: agent directives, publish, testing.
